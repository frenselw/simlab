## 本輪交付與決策

使用者要求先審閱計劃與可運行的基本結果，再決定正式整合。本輪交付獨立原型、實際 WebGL 截圖、下載請求與數值自查。原型入口為 [預覽頁](../tools/prototypes/rocket-procedural-earth/index.html)。

本工作屬現有非評分活動的設計研究，評分、rubric、SCORM、作答快照與提交生命週期均為 N/A。設計及交付依循[共用規則](00-shared-platform-and-style.md)、[製作契約](../docs/simulation-scorm-production-guide.md)及[原活動計劃](42-rocket-side-booster-expansion-plan.md)。

## 生成方法

固定 seed 及球面位置決定唯一結果。以少量手寫參數描述大洲的粗略形狀和主要山帶，再用連續噪聲扭曲邊界。這些參數與程式一起傳輸。它們是設計數值，實際海岸、山峰和城市的位置不作地理承諾。

地面高度由大陸基底、山帶權重、連續山脊噪聲、丘陵與小尺度起伏組合。噪聲使用球面三維座標，跨經度接縫可連續，極點位置固定。海面截取海拔零。發射台整地使用固定位置的平滑權重，平整核心外漸接原地形。

原型固定 seed 為 731，以可旋轉的橢圓形區域描述大洲、半島及島嶼，並以平滑聯集接合重疊區域。球面噪聲塑造起伏海岸，額外細節只在海陸交界附近計算。高度與海岸渲染共用同一海陸邊界，地表顏色由淺水經岸邊漸變至陸地。六組線段及寬度描述主要山帶。位置先轉為球面單位向量，連續 value noise 疊加不同頻率。山帶強度由到線段的距離平滑衰減，山脊使用 `1 - abs(2 * noise - 1)` 的平方，再以低頻山體與次級山脊調節。沙丘使用被噪聲扭曲的方向性波形。所有高度被限制於 −5,000 至 8,500 m，海平面為 0 m。

沙漠與植被由緯度、濕度、海拔決定，陡坡露出岩石，高山及極區積雪。地表色彩在載入時運算成一張記憶體紋理，近景網格的高度與顏色直接取樣同一函數。生成後重用，避免每一幀重算全球。雲層由 shader 的連續噪聲產生，光照與地球共用太陽方向。這裡的「零素材下載」指無高度檔、衛星圖、法線瓦片或雲圖的網絡請求，記憶體仍會儲存運算結果。

## 原型範圍與畫質判斷

提供地球、山脈雪地、森林丘陵、沙漠四個觀察位置。地球可旋轉、縮放，區域可拖曳環看、平移、縮放。地球與區域都用真實比例的高度。區域為有限展示視窗，其外邊界屬原型裁切。

原型以地表色彩展示大尺度植被，森林近景再加入有限數量的程序樹木。雲層屬視覺近似。完整水文侵蝕、河網及真實天氣可列為往後的藝術需求，先以本次結果判斷山形是否自然。煙霧已由現有程式生成，可沿用其粒子系統改進受光，本原型先驗證地球與地形。

桌面及手機使用同一頁，頂部提供共用全螢幕、短控制列及可操作畫布。原型沒有保存或評分。手機 trusted touch、完整 Moodle 宿主矩陣與發布套件留在正式整合驗收，原型檢查桌面、手機尺寸與基本觸控。

## 驗證門檻與階段

1. 本輪檢查固定位置可重現、反經線與極點、山脈和平原高度、海陸分布、數值有限及高度上界。保存真正瀏覽器渲染截圖與所有請求，檢查離線後切換展示位置。
2. 使用者確認畫質方向後，正式接合高度函數和區域網格。抽查網格與物理高度，近場垂直差目標不超過 0.25 m。採樣加密或投射到同一三角形解決插值差。平整發射台、道路接縫及水邊另測。
3. 對完整升空、分離、返航、海上濺落、山坡着陸、遠距探索、加速及往返鏡頭作回歸。舊測試初始位置需依新地形查驗。測失敗重試、WebGL 恢復、取消生成及切換區域。
4. 比較同機冷快取首次可組裝、可發射、完整返航及跨區探索的實際 bytes、耗時、長任務、CPU／GPU 記憶體與幀時間。初步目標為整頁首次傳輸低於 1.5 MB，地形資料請求 0，正常探索後不新增地形網絡請求。這是整合驗收目標，原型結果另記。
5. 真手機以至少一部 Android 及一部 iPhone 確認操作與長時間發熱。畫質驗收同時看海岸、山脊、平原及從太空接近地面，通過才替換現行版本並發布。

正式區域生成採球面分區和固定世界座標，地球低細節先可用。可見近區才細分，工作移入 Worker 並設任務版本，舊任務完成後不覆蓋新視角。相鄰區塊共用邊界高度與法線，接縫與細節切換要有網格銜接和漸變。緩存以固定 bytes 限制，旋轉鏡頭不重新運算整個星球。地面接觸仍以獨立於視角的固定高度規則判定。

狀態矩陣至少包括工廠先可操作／生成中、生成成功／失敗重試、發射台平整區、海陸交界、山坡、極點、反經線、軌道及遠距畫面。地球雲層 shader 可重用現有光照方向。正式版本若需動態雲層，只更新時間參數，保持固定雲場及可控迭代次數。

### 本輪實際找出的限制

1. 粗網格與公式高度有差別。桌面各網格抽樣三角形中央點，最大差約為雪山 **135.93 m**、森林 **13.19 m**、沙漠 **0.75 m**。這項檢查是視覺原型的診斷，結果明確未達正式接地的 0.25 m 目標。正式整合必須增加近場解析度、估算誤差並與固定碰撞面對齊。原型樹根已使用實際網格的三角形插值貼地。
2. 近景生成目前在主執行緒，有約半秒停頓。正式版本的分區、Worker、取消和分批提交仍需驗證，避免把減下載的成本轉為操作卡頓。
3. 大洲為粗略手寫形狀，地形屬合成地球。山脊侵蝕細節、森林樹形和地表細節仍簡化。區域視窗有有限邊界；連續從軌道接近同一地面、無縫 LOD 及飛行着陸尚待接合驗收。原型球體的幾何為球面，地球遠景顏色取自同一高度函數，尚未展示全球真實起伏的輪廓。
4. 雲層為靜態程序 shader；手機 globe 色彩解析度較低。沒有量度真手機 FPS、發熱、GPU 峰值記憶體及長時間探索；不能以本輪生成秒數推論這些項目。

本原型已證實零外部地形／圖片資料的視覺生成和離線切換可行。

## 原活動試飛版

使用者確認後，在同一分支接入[原活動入口](../sim/rocket-side-booster-lab/index.html)。`procedural-earth.js` 同時供原型與原活動使用。原活動的全球高度、海陸顏色、雲層和碰撞高度從固定公式計算。發射台周圍的 2.6 km 核心平坦，原道路和設施仍按地面定位。人工地形在區域外平滑接回全球公式。

地球圖和雲層由 Worker 生成。桌面地球地圖為 2048 × 1024，手機版首載為 1024 × 512，放大到足夠看清地球時才在本機加密到 2048 × 1024。全球底色、發射區共邊網格與近地接觸網格在不同距離提供畫面。飛離發射區後，按航行位置生成有限大小的地面網格，遠離近地視角時收起。

飛行物理保留原來使用的 `RocketSurface` 高度、離地高度及海陸介面。使用渲染三角形作射線量測，抽查發射台、道路、發射區、海岸、海面及遠地 11 個點，中心地面與碰撞高度的最大差為 **0.087 m**。這是抽查值。粗地形過渡和長時間飛行時的近地生成成本仍需實體裝置驗證。

獨立版資產從 5,337 個減至 37 個。舊高程、預建地形、地球及雲圖、地形瓦片與高程中繼均退出活動套件。獨立的歷史地形樣本頁、星空背景及日月曆表仍隨包提供。第一輪桌面冷快取三次都量得約 **1.27 MB** 的總 HTTP body，地形資料為 **0 B**；斷網完成發射、分艙、開傘及着陸後沒有增加流量。完整軌道返航與兩段開傘由模型測試驗證。

解壓版 Chrome 測試共完成 25 條記錄，涵蓋生成失敗重試、發射台道路、遠地形、日夜、海陸着陸及十萬公里以上飛行與鏡頭操作。再次冷載三次均為 1,269,135 bytes，完成斷網着陸後仍為同一數值。17 項火箭 Node 測試通過，ZIP 37 檔逐一核對來源。試飛包為 3,419,949 bytes。詳見[瀏覽器記錄](../output/playwright/rocket-side-booster-lab/explorer-report.json)。

### 地形細節更新

在海岸加入更小尺度的海灣和岬角。發射區的近岸材質以物理海岸公式逐像素判定海陸，山坡使用山麓、山谷高度和隨屏幕比例淡出的地表紋理。遠地網格以飛船下方加密，中心間距由約 6 km 減至手機約 0.55 km、桌面約 0.44 km，透過同一 Worker 接續生成。桌面放大地球後可生成 4096 × 2048 地圖，手機上限維持 2048 × 1024。

18 個 Node 測試及解壓版瀏覽器測試通過。斷網時成功切換並重算遠地網格，也成功生成桌面 4096 × 2048 地圖。冷載三次均為 1,276,239 bytes 的本機 HTTP body，新增地形資料傳輸為 0 bytes，斷網發射至着陸後總數維持。詳見[本輪瀏覽器記錄](../output/reports/rocket-procedural-detail-browser.json)。實體手機的生成速度、畫面帧率與耗電待驗。

### 發射場近景更新

保留發射台中心 45 m 的平坦區，山坡和地面碰撞使用同一高度公式。以相同數量的三角形將發射場接觸網格的中心間距由約 117 m 減至約 12 m，並加密低空區域網格。發射場近景以幾何法線表現實際地形，遠處平滑接回地表微細紋理。道路用共用路線座標在材質內畫出連續邊線和虛線，稀疏灌木避開道路和設施。

解壓版 Chrome 用 390 px 手機視窗驗證。台面和停機坪抽查高度均為 0 m，兩側山坡測得約 60 m 和 91 m。道路材質通過實際 WebGL 像素取樣，地表和物件根部通過射線及貼地檢查。18 個 Node 測試通過，三次冷載均為 1,279,852 bytes，斷網操作至着陸後維持同一流量。[瀏覽器記錄](../output/reports/rocket-launch-ground-browser.json)

### 低空草地及點火畫面

以相同低空視角關閉所有樹木，確認重疊的模糊深綠色仍然可見。發射區改用較細的草皮和乾土色澤，按畫面像素覆蓋範圍淡出。坡地加淺溝，區域網格重新分配頂點，使較密的三角形延伸至原發射台外圍。接地與貼地輔助物直接索引實際區域三角形。點火前準備蒸氣與火焰材質，發射台上的火箭跳過無效的軌道預測。飛行動畫每幀合併儀表、鏡頭及效果的繪畫要求，原有 1.5 秒點火停留按實際經過時間扣減。

以 Chrome 軟件 WebGL 和 390 px 視窗重現，點火觀察窗內重複繪畫的幀由 8 幀降至 0 幀，仍錄得較長的繪畫。區域網格高度與實際 WebGL 場景三角形射線對照通過。18 個 Node 測試及 12 條解壓版瀏覽器記錄通過。三次本機冷載均為 1,282,069 bytes，斷網操作至着陸後維持同一流量。實體手機幀率仍待實測。[本輪瀏覽器記錄](../output/reports/rocket-low-flight-browser.json)

### 跟隨視角的遠距地球黑格

在 390 px 視窗、離地 30,000 km 重現向陽海面上的黑色多邊形。移除雲、大氣、飛船與星點後測得相同黑格。增加鏡頭近裁剪距離或改用對數深度裁剪的地球材質後，黑格位置恢復海面顏色。大氣層外的透視場景保留原鏡頭設定，讓地球、雲和大氣以對數深度寫入片段深度。地球本身寫入深度，取代遠距的重複深度球。近地及正交軌道保留各自的深度設定。

離地 17,000、30,000、57,000 及 98,500 km 共 12 組角度和縮放檢查中，向陽區約 74 萬個畫素均無黑格。30,000 km 同一視角關掉修正後重現 267 個異常暗畫素，三個實際截圖樣點亦由黑色恢復海面顏色。遠距鏡頭、日月及 WebGL 恢復、軌道、發射台共 20 條解壓版瀏覽器記錄通過。[瀏覽器記錄](../output/reports/rocket-distant-globe-browser.json)
