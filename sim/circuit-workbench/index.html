開始搭建電路

  1. 在工具箱點選元件，拖動本體調整位置。
  2. 點兩個端子即可接線，也可直接從端子拖到另一端子。
  3. 接線時點空白處指定轉折；點既有導線可接出分支。
  4. 選取元件後可旋轉、刪除、複製及調整參數。
  5. 線路交叉不代表接通；實心接點才代表分支。

鍵盤：Tab 選端子，Enter 接線；方向鍵移動所選元件，R 旋轉，Delete 刪除，Escape 取消，Ctrl／⌘ Z 復原。

儀表接法

A 表串聯，V 表並聯。W 表的 I+／I− 串聯，V+／V− 跨接用電器；讀值為 (V+ − V−) × 電流線圈電流。反接會顯示負值。

模型與參考點

電源預設理想內阻 0 Ω，可自行調整。理想 V 表不耗電；輸入電阻欄填 0 代表無限大。熱效應燈以額定點校準的溫度／散熱模型計算，不模擬預熱或燒毀。

探測工具可量兩點電壓；按所選端子的「設為 0 V」改參考。互不相連的電路沒有確定的跨區電壓。方向動畫只示意漂移方向，不是真實電子速度。
