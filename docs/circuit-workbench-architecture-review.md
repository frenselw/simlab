# 電路工作台共用架構審視（2026-10-04）

目前的接線與直流求解核心適合重用，不需要為每個活動重做。但現有教師工作台還不是可用一份設定裁剪的活動編輯器：元件工具箱和設定介面固定寫在 `main.js`／`index.html`，操作模式亦可在教師設定中解除。不能把固定模式直接當作學生版。

本輪已移除記錄表、圖像、擬合、CSV 及 `circuit-experiments.js`，核心不再依賴實驗功能。實際電錶、兩點探測、功率／電阻計算及方向動畫保留。未新增學生模式或活動設定框架；下述配置介面是建議，尚未實作。

## 現況與缺口

| 活動需要 | 現況 | 尚需整理 |
|---|---|---|
| 給定元件，只讓學生接線 | `policy.mode="wiring"` 可固定元件；導線仍可取用、接好及彎曲 | 學生活動須由外層固定規則，不能顯示可解除限制的教師設定 |
| 完全不顯示某些元件 | 核心只求解文件中的元件；工具箱卻固定建立全部類型及兩種燈 | 按活動白名單建立工具箱，不生成不允許的按鈕；另限制各類可取數量 |
| 隱藏教師／進階功能 | 顯示數值有開關，齒輪仍包含所有教師設定 | 由活動外層決定是否建立設定、文件、範例、探測等介面 |
| 只允許某些操作 | 有固定模式、旋轉／參數／開關權限及元件 `locked/editable` | 新增統一命令入口；滑鼠、觸控、鍵盤、面板及載入都受同一規則限制 |
| 只允許修改指定參數 | `editable` 目前開放該元件全部參數 | 活動可指定只改滑片位置或某個阻值，固定量程、模型等其餘參數 |
| 提交後只讀 | 固定模式仍可改線，不等於只讀 | 增加編輯／只讀能力；只讀仍可移圖、縮放、全螢幕及讀錶 |
| 加入新的直流元件 | registry 支援多端子、支路及非線性模型；renderer 可自訂本體 | 工具箱、內部流動路徑及部分說明仍按內建型別處理，需補擴充鉤子 |
| 接到不同活動的題目／評分 | 已有 `onChange/getDocument/getAnalysis/loadDocument` | 評分、題目、階段、記錄與 SCORM 放在活動外層，不加回核心 |
| 同頁切換／卸載編輯器 | `main.js` 自動啟動單一全域 instance，依賴固定 ID | 抽成 `mount`，回傳 controller 與 `destroy`；移除事件、RAF、observer 及捕獲 |

## 建議邊界

1. **共用電路引擎**：registry、model、solver、routing、document。擁有端子、拓撲、有限導線、電學與嚴格資料驗證；不認識教師、題目、分數或記錄表。renderer、字形及指針運動保留為共用顯示工具。
2. **可配置電路編輯器**：從目前 `main.js` 抽出畫布、相機、命中、接線、預覽及命令；按配置建立需要的工具列及工具箱。建立多個 instance 或換活動時均能完整卸載。
3. **不同外層**：教師工作台提供完整工具；學生活動只提供本題需要的元件與操作；實驗活動如有需要，自行提供記錄和畫圖；SCORM 外層擁有題目、評分、階段、提交、恢復及只讀狀態。

共同元件不應因活動不使用而從 registry 刪除；白名單控制提供哪些元件。若某元件仍參與電路求解但刻意隱藏畫面，必須由活動明確定義其教學用途及連接方式，不能只把圖形藏起來，留下看不見的吸附點。

## 配置應分開的四件事

- **供應**：元件型別／燈模型、各類數量、導線庫存及長度；預置元件能否搬動。
- **介面**：是否顯示工具箱、探測、外觀切換、方向示意、讀值、範例、文件、教師設定；不允許的內容不生成，也不進鍵盤焦點序列。
- **命令權限**：能否新增、刪除、旋轉、接線、拔線、改參數、開關、清空、匯入及復原；隱藏按鈕與禁止命令不是同一件事。
- **活動狀態**：初始電路、固定資料、學生作答及編輯／只讀階段。活動規則從可信的本地程式提供，不跟學生電路文件一起匯入；載入及復原後仍套用當前活動限制。

例如「兩燈串聯接線」應只放出電源、開關、兩盞燈及 6 條線；元件工具箱、教師設定、範例及文件按鈕全部不生成，學生只接線／拔線／彎線／開關，畫布仍可雙指導航及讀取結果。「自由設計串並聯」則可放出電源、開關、恆阻燈，設定每類數量，允許搬動／旋轉／刪除，仍隱藏教師設定。兩者都沿用相同的端子、吸附、線形及求解。

這些配置應由活動檔直接宣告，無需新增一個學生能開啟的複雜設定畫面。先實作這兩種小配置，再按真實需要擴展，不先建立大型通用活動系統。

## 現有 API 的保留與補充

保留文件／分析的副本、兩點電壓、已提交變更訂閱及取消拖動。建議 controller 另提供 `setReadOnly`、`destroy` 和受權限檢查的命令入口；UI 不直接改 document。相機、粒子位移、針頭慣性與開合視窗仍是暫態，不能寫進作答。

教師 JSON 可達 256 KiB，不能直接當作 SCORM 1.2 的 ≤4000 bytes 作答快照。接線活動應由外層保存題目版本及必要的端點關係／幾何／參數，載入後重算；blank／partial／review／pending 的合法狀態與提交由各活動按[production guide](simulation-scorm-production-guide.md)處理。前端操作限制是教學規則，高風險評分仍需要可信驗證。

二極管等穩態元件可繼續利用非線性支路擴充；電容、電感、繼電器的時間行為需要另外設計步進、狀態及能量驗證，現有 DC 求解器不自動支援瞬態。

## 建議優先次序

先抽出可掛載／卸載的編輯器並保留教師工作台行為；接著補元件白名單與庫存、介面可見性、統一命令權限及只讀。以「固定兩燈，只接線」證明其他工具完全不出現、鍵盤／載入／復原也不能越過活動限制。最後由獨立活動接入題目、評分及 SCORM；記錄圖像只在需要它的實驗活動出現。
