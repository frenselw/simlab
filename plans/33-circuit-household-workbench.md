# 家庭電路工作台：概念與接線計劃

更新：2026-10-14。**狀態：用戶已批准，實作與驗收進行中。**

本版完整取代舊計劃。先前撤回的程式、兩個原型、十八個示例及其驗收紀錄均不作為本版設計或完成證據。用戶已批准按本版完整實施；第 11 節的重寫證據保留為歷史紀錄，實作證據另記。

目標是讓中學生在熟悉的 DC 工作台內，用少量圖形元件接線、開關和比較，理解：**火線與零線如何供電、地線如何連到金屬外殼、哪些情況會有人體電流，以及不同保護裝置何時切斷電路。**

需求中的「開關連到零件」按「開關接到零線」理解；未填名稱的第（11）項，依漏電示例補為「漏電保護器」。

**接線需求以最新補充為準：用電器端必須容許學生接錯。** 原先「禁止 L／N／E 連錯位置」收窄為供電側的固定端子及直接短接限制，不能用它攔截用電器兩條工作線同接 L、同接 N、同接 E，或跨接 L–E 等探索。具體範圍及結果見第 4 節。

- 每個示例只有一個小電路，一般 4–6 件元件；一屏只比較一件事。切換條件在原圖發生，不並排堆兩套大電路。

- 常駐標示只留元件名稱、L／N／E、必要額定值及當前狀態。電流、對地電壓等讀值選取後才顯示。

- 斷開時保留導線顏色；「沒有工作電流」與「仍相對地帶電」分開顯示，不能一律變灰。
- 家庭功能由配置及共用擴充接入，不另造分頁式課程、全屋面板或第二套畫布。

### 版面與文字

沿用 DC 的三區及 `bounded split-panel`：桌面畫布在左、252 px 面板在右；759 px 以下畫布在上、面板在下；短橫屏沿用共用 CSS 的雙欄安排。短視窗保留至少 96 CSS px 可用面板，最後一項控制可達。任何必要的共通版面修正回到共用 CSS，連同 DC 驗證。

主控制 16 px、圖上必要文字實際顯示至少 14 px、互動目標至少 44 px。完整小電路適應畫布時仍須辨認三個插孔及外殼接地；不能只把圖縮小到字看不清。全螢幕沿用 shared fullscreen 標記與腳本，涵蓋完整工作台。

### 插座與家電的畫法

三孔使用**插座正面視角**。每孔是一個電氣節點；供電側按固定身份接入，家電側接到學生實際選中的孔，以簡化透視線顯示導通，不額外增加六個容易混淆的孔。同一孔可容納多個圖上連接，兩條家電引線同接一孔時，共接關係與兩條線都要看得見，不能被單線命中或圖層覆蓋。這是接線原理圖，不模擬把裸線插入插座。首版不新增獨立插頭、插拔動畫或鏡像視角。

金屬外殼元件的 E 引線–外殼連線始終可見；正確接線時的正常工作路徑為 L–負載–N，不經外殼。錯接時保留原有線芯顏色、L／N／E 標示及內部接點，不能偷偷交換標籤或重畫成正確接法。雙重絕緣元件即使內層出現裂口，也要看得見仍完整的第二層。

上述功率是選定教學款式的**額定輸入功率**；冷氣的 1000 W 不表示製冷量，同一類家電也不一律屬同一絕緣類別。切換款式保留元件 ID、位置、相應接線及故障狀態，重算負載；不自動復位保護裝置。

### 元件繪圖與品質標準

**家庭版以目前 AC 工作台的實物元件作為畫風及完成度基準。** 沿用細緻的 SVG 器材插圖：物件輪廓易認、比例協調，以柔和邊線、少量漸層、高光、薄側面及正確遮擋表達材質。這是本版交付要求，不能只以「已畫出元件」或「端子能操作」判定完成。

基準來自[AC 實物繪圖說明](../docs/circuit-ac-workbench.md#實物符號及燈光)、[變壓器鐵芯與繞線](../docs/circuit-ac-workbench.md#變壓器鐵芯與磁通觀察)及目前的[AC 元件原始碼](../sim/circuit-workbench/circuit-ac-components.js)。製作時把現有元件與新元件以相近顯示尺寸並排檢視：

| 現有參考 | 家庭版要承接的品質 |
|---|---|
| AC 電表 | 灰藍外殼、白色讀值面、內外框層次、克制高光、端子與文字的留白；電能表改成 kWh 視窗，保留同等殼體完成度 |
| 電感 | 圓筒側面、前後層遮擋、連續而平滑的導線；家庭電纜、接地線與內部連線也要真正接到其目標 |
| 變壓器 | 薄側面／疊片表達厚度、銅線明暗、鐵芯與繞線的前後關係；家庭元件同樣以有限而準確的細節表達結構 |
| 平行板電容 | 一致投影、薄金屬邊、乾淨板面、引線準確落在接點；新器件的透視與端子位置亦要一致 |

**全套繪圖規則：**

- 配色沿用現有器材的白／灰藍殼體及柔和金屬色；例如電表殼體 `#e8f0f6`、外框 `#446482`、內框 `#b2c2cf`。金屬和塑膠以不同明暗及邊緣處理區分；L／N／E 的功能色仍按接線規則。
- 參考 AC 電表外框 2、內框 1 世界單位的線條層級；按新元件原生尺寸統一校準外輪廓、內部結構和細節線，圓角及線端處理保持一致。不得讓每款元件各用一套粗幼或誇張粗黑邊。
- 插座、電表、開關及保護器以清楚的正面為主，輔以薄側邊／倒角；家電採一致的正面或輕微側視。光源方向一致，明暗用於交代形狀；避免大面積投影、強烈光暈或過多擬真紋理搶走接線。
- 實物造型必須可辨認，不能靠名稱才分得出風扇、冷氣及熱水器；不用 emoji、文字方框、佔位圖或符號模式圖案充當完成的實物圖。符號視圖另外保持簡潔，切換不改端子身份及接線。
- 內部教學結構用整合於本體的小型剖視／透視區表達；保留外形辨識度，只露出負載、絕緣、外殼及必要接線。不要為每件器材另加一塊解說圖。
- 可接線位置與實物接孔中心一致，三孔的長方形凹孔仍清楚可見；共用命中區及高亮環不得遮住孔形。裝飾螺絲不能畫成另一個可接線孔；外殼接觸區也不能冒充 E 接孔。
- 主畫布、工具箱縮圖、接線放大預覽及匯出圖使用同一份元件幾何；沿用共用 renderer、端子及文字排版。小縮圖可省略次要細節，但外形、接線身份及主要材質一致，不另畫一套草率圖示。
- SVG 的漸層、遮罩和裁切 ID 按 editor／元件／視圖分域；同款多件、預覽及多工作台並存時不能串色、漏圖。旋轉、縮放及狀態切換不能造成接點漂移、穿殼、斷線或文字倒轉。

### 繪圖驗收

後續 P0 先製作**元件圖鑑與小電路樣稿**：逐款實物圖、主要狀態，以及 C01／C03 的實際大小排版；圖鑑只供製作與驗收，不加入學生主畫面。先修正造型與畫面問題，再擴充全部示例。

- 將新元件與上述 AC 基準並排檢視，確認材質、線條精細度、比例及完成度相稱；每一類及可切換家電款式都要看過實際渲染。
- 保留桌面正常尺度、200% 細節，以及 320／390 px 手機實際畫布截圖；正常尺度能認出物件，放大後線條仍乾淨，手機不用先放大才辨認插孔、手柄及接地外殼。
- 檢視正常、開路、跳掣、熔斷、兩類絕緣破損、人物接觸及站椅狀態；只改相關局部，不造成整件變形、線路跳動或接觸位置失準。
- 檢視工具箱縮圖、實物／符號、預覽、支援旋轉角度及多件同款；另以 C08 確認兩條線接同孔仍可辨認及分別操作。文字不重疊，線路不穿過不相關物件，必要細節不被選取框或命中提示遮住。
- 視覺缺陷須修正後重看受影響畫面；記錄參考版本、截圖及檢視結果。自動幾何檢查輔助核對端點／邊界，不能取代實際圖像檢視，也不能以測試全綠代替繪圖品質。

## 4. 接線規則：容許用電器接錯，再觀察結果

### 預定用途、實際連接與電勢分開

- 供電側的市電、電表、斷路器、漏電保護器及插座有固定 L／N／E 端子身份；這些端子的供電接法仍受限制。
- **用電器引線上的 L／N／E 只表示預定用途，不能當作拒絕錯接的硬性配對條件。** 兩條工作引線可各自接入任一 L／N／E 節點，兩條也可接到同一節點；兩類用電器及所有款式一致適用。金屬外殼的 E 引線亦可錯接 L／N，或留空。
- 線色仍為 L 棕、N 藍、E 黃綠雙色，另有字母。家電自帶線芯的原色與標示固定；一般自由導線未接已知供電端時為灰色，接上後由實際供電節點推導。不能因錯接而把家電藍色線芯改成棕色，或把插座 N 孔改名為 L。
- 固定身份沿外部導線、共接點、插座同孔、電表／保護器的各自通道傳遞；普通開關兩端即使斷開，也須屬同一供電角色。**家電端子的預定用途不向外傳成固定身份；角色不跨負載、電源、故障支路或人體傳遞。** 實際電氣求解仍包含這些支路。
- 拔線後重新推導實際連接；不保留過時身份。接錯、自由端、未接齊或未接地都是可保存的學習狀態，不能自動修正。
- 電勢由模型求出，不由線色或標籤決定：藍色家電引線誤接 L，或零線開關斷開後的負載側藍線，都可能相對地帶電。

### 開放與限制的界線

| 嘗試接法 | 結果 |
|---|---|
| 供電側 L 接 L、N 接 N、E 接 E；同角色分支 | 接受；電表及保護器仍按各自通道連接 |
| 供電側固定 L／N／E 端子互接，或用一條線／共接點直接短接不同供電角色 | 拒絕；例如電表 L 出接插座 N，或直接把插座 L、E 合併。短句說明被限制的是供電端接法 |
| 家電的兩條工作引線接 L／N／E 任意組合，包括兩條同接一孔 | **接受全部九種組合**；不要求先啟用「錯接模式」，也不只在指定示例開放 |
| 家電 E 引線接 E、錯接 L／N，或不接 | **接受**；外殼跟隨實際接入的節點。錯接 L 時即使絕緣完整，外殼也可能帶電；錯接 N 不視為正確保護接地；不接時不自動補地線 |
| 經家電負載形成 L–N、L–E 或 N–E 通路 | 接受；負載兩端接不同角色不等於用裸導線把供電端短接 |
| 普通開關串在火線／零線 | 均接受；接 N 時給「開關接在零線」的中性提示，保留原比較 |
| 開關兩端分別接不同供電角色，或串入 E；保險絲串在 N／E | 拒絕；本版仍只開放同一 L／N 線路上的開關及火線保險絲 |
| 接地符號的引線接插座 E | 接受；其餘目標仍拒絕，包含經中間共接點繞道。這個專用符號與家電 E 引線是不同的接線規則 |
| 人的手碰外殼 | 走獨立「接觸」操作；不是接線，不受 L／N／E 配對規則誤擋 |
| 圖上導線交叉但沒有接點 | 不導通；沿用 DC 的明確共接點操作 |

**所有入口執行同一規則。** 拖線、拖元件靠近線端、兩端同時吸附、共接點合併、鍵盤接線、公開命令、示例載入及文件匯入都要同時支援上述錯接與限制。驗證整個共接網路時，只以供電側固定身份判斷角色衝突，不把家電端子的預定用途加入衝突集合。若同一根家電引線再把固定 L 與 N／E 節點直接合併，仍屬直接短接；但家電兩個不同負載端子同接 L 必須成功。真正違反限制的操作原子拒絕，不留下半次接線或多餘復原紀錄。

### 用電器兩條工作引線的接法與結果

下表依序寫「家電標 L 的引線接哪裏、標 N 的引線接哪裏」。基準為同一個正常供電的插座、E 已接等效地、絕緣完整、沒有人接觸，金屬外殼 E 引線若存在則正確接 E。這是第 6 節電阻模型的推論及驗收基準；其他接法／故障／保護狀態按實際電路重算。

| 接到的節點 | 基準結果及要呈現的概念 |
|---|---|
| L–N | 兩端約 230 V，正常工作 |
| N–L | 兩端仍有約 230 V；本版電阻等效負載可工作，但預定 L／N 已反接，不能因能工作便顯示「接線正確」 |
| L–L | 同一節點，負載兩端電壓為 0，沒有工作電流；兩條工作引線仍相對地帶電，不能顯示為已隔離或安全 |
| N–N | 同一節點，負載兩端電壓為 0，沒有工作電流；不能因此宣稱任何情況下觸碰均安全 |
| E–E | 同一節點，負載兩端電壓為 0，沒有工作電流；地線不能因此被解讀為第二組正常供電孔 |
| N–E、E–N | 本基準中兩端近 0 V，電器不工作；不同節點間的實際壓降仍交求解器計算，不能把 N 與 E 視為可互換的接線身份 |
| L–E、E–L | 地回路完整時可有約 230 V 及工作電流，但電流錯經地線回流。若 L 經漏電保護器而回流繞過其 N 通道，按實際差流及延時跳掣；不能一律當開路，也不能只看「接錯」就跳掣 |

E 未接地、保護已斷開、只有一條工作線接上，或另有人體／故障回路時，上表不能作硬編碼答案；重新求兩端電壓、各支路電流及外殼電勢。尤其 L–E 在 E 懸浮且沒有其他回流路徑時可不工作，懸浮側卻仍可能被負載連到火線電勢。

錯接放手後仍留在學生選的位置，不彈回、不改接最近的正確孔、不彈阻塞對話框。畫面只保留一個當前觀察句，例如「兩條線同接火線，電器沒有工作電流」；選取後才顯示兩端電壓、對地電壓及「本應接 N，現接 L」等說明。九種組合表只供規格與驗收，不搬到學生畫面作九張資訊卡。

### 「開關接零線」示例的必要條件

此比較固定家電兩條工作引線按 L→L、N→N 接好，只改開關位置；先正常工作，斷開火線開關或零線開關都能使它停止。再以**相同的外殼絕緣破損、家電 E 引線未接、人在地上並接觸外殼**比較：

- 斷火線：故障點與火線電源隔離，本例沒有持續人體電流。
- 斷零線：火線仍連到故障點，電流可經外殼、人體及接地回路回到電源。
- 絕緣完整時，不能只因開關在零線便畫出外殼漏電；人未接觸或理想絕緣離地時，也不能畫出持續人體電流。

## 5. 全新示例：每次只看一個概念

八個示例均重新編排。選單直接切換獨立示例；沒有解鎖、答題次序或先完成前題的要求。載入示例是可復原的文件替換，狀態不與前例混用；不是自動替學生接好自行搭建中的電路。全部示例均容許第 4 節的家電錯接，結果隨實際接線更新，不鎖定為示例預設答案。

| 示例 | 畫面中的元件 | 主要操作 | 應看見／說得出的重點 |
|---|---|---|---|
| **C01 家庭電路怎樣接** | 市電、電能表、斷路器、一個插座、一件金屬外殼家電、接地，共 6 件 | 沿兩條線查看電表及斷路器的入／出，開合斷路器 | L／N 經電表及斷路器到插座；E 經插座接外殼；正常用電不經 E，電表累積電能 |
| **C02 開關應接哪條線** | 市電、插座、普通開關、金屬外殼家電、人，共 5 件；E 明示未接 | 把同一開關移到 L／N；斷開，再切換故障及接觸 | 電器停止與火線隔離是兩件事；按上節必要條件呈現人體電流 |
| **C03 地線如何保護人** | 市電、插座、金屬外殼家電、接地、人，共 5 件 | 保持外殼絕緣破損，接上／拔開 E；比較人接觸前後 | 接地把外殼接到低阻回路；本版理想地線使外殼電勢下降。斷 E 不妨礙正常用電，卻失去這條保護通路 |
| **C04 漏電保護器為何跳掣** | 市電、漏電保護器、插座、金屬外殼家電、接地、人，共 6 件 | 正常→外殼絕緣破損；再比較 E 未接、無人接觸及人接觸 | 電流有一部分經地線或人體回流，沒有經保護器 N 通道返回，才產生差流；不依「故障」按鈕直接跳掣 |
| **C05 雙重絕緣多了一層甚麼** | 市電、插座、雙重絕緣家電、人，共 4 件 | 切換內層破損；人在地上接觸外表 | 第二層仍隔離內部帶電部分；這個指定故障不形成對外漏電，也不需要 E |
| **C06 兩件家電為何並聯** | 市電、兩個插座、兩件雙重絕緣家電，共 5 件 | 拔開其中一件的 L 線；再換較大功率款式 | 另一件仍可工作；各支路跨接 L／N，總電流是各支路之和。只畫兩支路 |
| **C07 斷路器與保險絲保護甚麼** | 市電、一種過電流保護元件、插座、2000 W 金屬外殼家電、接地，共 5 件 | 選 5／15／30 A 斷路器，或載入同布局的保險絲變式比較 3／5／13 A | 同一負載約 8.7 A；較小額定值會動作，較大者不會。斷路器可復位，熔絲需更換；沒有漏電差流時不能冒稱漏電跳掣 |
| **C08 兩條線接到哪裏** | 市電、插座、雙重絕緣台燈、接地，共 4 件 | 直接拖動兩條工作引線，比較 L–N、兩線同孔、L／N 反接、L–E；拔開接地看回路差別 | 由兩端電壓及回路決定是否工作；不亮不代表不帶電，能亮也不表示接法正確。一次只呈現當前接法及一句結果 |

C01 預設 15 A 斷路器與 2000 W 熱水器；C02–C04 用 60 W 金屬外殼風扇，C05 用 40 W 雙重絕緣台燈，C06 用台燈與 60 W 雙重絕緣風扇；C07 從 15 A 斷路器／13 A 保險絲開始，改小規格後再觀察動作；C08 用 40 W 台燈，起始兩線正接 L／N、插座 E 已接地。各例從正常、開關合上、人物未接觸開始；需要人物時預設站地上，故障由學生主動切換。C03–C04 預設 E 已接，拔開後才形成無地線的對照。

C03 專注接地回路，C04 才加入漏電自動切斷，避免每例同時講全部保護。C07 在既有示例選單提供斷路器／保險絲兩個變式，仍只顯示一種保護；保險絲變式的 N 直接連插座，不虛構保險絲的零線通道。除這個明確變式外，各比較都在原圖操作。

C08 專注兩條工作線，不加入人物、電表或保護器，也不新增接法按鈕排；用原有拖線及讀值操作探索。需要觀察 L–E 錯接後跳掣時，在 C04 原圖改接家電工作線，並保持絕緣完整，以分清「錯把地線當回線」與「絕緣破損漏向外殼」。

故障及跳掣以局部導線／接點／外殼狀態和一句結果表達。若曾有人體電流後才跳掣，結果必須說「曾有電流通過人體，現已切斷」，不能直接顯示「安全」。

## 6. 物理模型：服務概念，讀值保持一致

採單一市電源的有效值電阻模型，另計保護延時和電能；不逐點積分 50 Hz 波形。電壓／電流標有效值，功率為平均有功功率。交流流動若開啟，只以雙向往返作概念示意，不畫成永久由 L 向 N 流的直流。

| 項目 | 首版規則／常數 |
|---|---|
| 市電 | 230 V、50 Hz 固定；L–N 為供電，電源 N 在供電端連到等效地參考。畫布只引出 L、N，不讓學生自行短接 N–E |
| 負載 | `R = 230² / 額定輸入功率`；依兩條工作引線實際所接節點求端電壓 `U`，再求 `I = U/R`、`P = U×I`。端子標示或「接線正誤」不直接決定工作狀態；同節點端電壓為 0，反接及 L–E 回路也須正常求解。風扇／冷氣亦採此教學等效，不模擬馬達啟動與功率因數 |
| 有限阻抗 | 電源內阻 0.01 Ω；電表、閉合開關及保護器每個通道 0.001 Ω。一般導線及 E–外殼視作理想導體；阻值不因畫面線長變化 |
| 金屬外殼及故障 | 外殼始終導通到家電 E 引線的實際接入節點；E 引線錯接 L 也會使完整外殼帶電，不依賴故障開關。「絕緣破損」另加入家電**標 L 的內部端子**至外殼的 2000 Ω 支路；反接後故障位置不追著供電火線移動。此支路表示受損絕緣，沒有回流路徑時可帶電而尚無漏電流 |
| 雙重絕緣故障 | 只破壞內層；完整外層仍為開路，不加入外殼漏電支路，也不偷偷改成 L–N 短路 |
| 人體 | 手接觸目標外殼；站地上時手至等效地取 2000 Ω，站絕緣椅時腳的通路開路。這是固定教學值，不能預測傷害程度 |
| 地線 | 接地符號表示連回供電系統的等效地，不是把電流「吸走」。正確接線且無故障時 E 無工作電流；工作引線錯接 E 時可承載負載回流，外殼故障時也可承載故障電流，均依實際回路計算。沒接地的插座 E 不自動連到模型地參考 |
| 過電流 | 斷路器／保險絲的電流連續大於所選額定值 2 個模擬秒後動作；回到額定值以下或斷電時清零計時。這是便於比較的教學延時，不標作真實器件曲線 |
| 漏電 | 比較同一保護器兩通道的有向電流；本模型為同相電阻負載，可用流出 L 與返回 N 的有效值差額。差流 ≥30 mA 持續 0.10 個模擬秒後兩極斷開；未達時清零計時。L–E 錯接即使絕緣完整，也可能因回流繞過 N 而動作；反接但兩通道仍平衡則不只因「接錯」而動作 |
| 復位／更換 | 由使用者操作；故障未排除時重新按電路計算並再次動作。移除故障或提高額定值不會自動合閘 |
| 電能 | 對電表實際供出的功率積分：`ΔE = P × Δt / 3,600,000` kWh。暫停時電能及保護計時同時凍結 |

保護事件按模擬時間處理，分割時間步到事件位置後重算；不依螢幕幀數。多個保護裝置同一時刻達條件時一同處理，再求解，避免結果依元件排列而變。接線／故障／規格改變後先重算，再推進時間。

對地讀值以供電端等效地為基準；不能像各個獨立 DC 小電路自行選零點，再把懸浮外殼報成 0 V。未能確定的電勢顯示「未定」。導體顏色不隨電勢改變；選取時可用額外輪廓提示仍帶電。

三項教學界限放在相關說明內：理想地線的降壓不等於所有實際接地都可靠；漏電保護器在電流發生後才動作，不能保證不受傷；絕緣椅狀態忽略潮濕、寄生電容及其他接觸，不能當作現實防觸電方法。雙重絕緣「仍不漏電」只適用於本例的單層破損。

供電數據依[澳電供電資料](https://www.cem-macau.com/en/about-cem/company-profile/operation/)；外殼接地與雙重絕緣概念核對[機電工程署電器安全說明](https://www.emsd.gov.hk/tc/electricity_safety/publications/general/household_electrical_safety_handbook/part_2/2_1/index.html)；線色及保險絲規格核對[Electrical Safety First](https://www.electricalsafetyfirst.org.uk/safety-advice/home-and-people/house-maintenance/plugs-and-fuses/)；30 mA 保護及其界限核對[HSE 電氣安全說明](https://www.hse.gov.uk/electricity/electricequip.htm)。上表阻抗及延時是本計劃自行選定的教學參數，不冒充上述來源的實物規格。

## 8. 文件狀態與操作一致性

以新封套識別本版文件：`kind: "simlab-household-concepts"`、`version: 1`、`model: "concept-rms-1"`。不把撤回原型的文件當作相容版本。

| 欄位 | 權威資料與驗證 |
|---|---|
| `circuit` | 沿用共用幾何結構的元件、接點、導線、ID、位置及線形；只接受本版十一類元件、枚舉款式／額定值及存在的端子。保存實際接到哪一孔，包括錯接、同孔多線及留空；只按第 4 節拒絕超出模型範圍的接法，不因家電標示與目標不同而拒絕。幾何文件為 `kind: simlab-household-circuit`、`version: 8`、`analysis: household`、`modelRevision: 1`，不能冒充 DC v6／AC v7；只有接地引線以 `anchor` 固定器件端；市電外接導線兩端均可拔接／刪除。舊檔市電 `anchor` 在驗證時移除，保留接線及幾何 |
| 元件參數 | 家電款式、故障枚舉、所選規格及人的 `grounded / insulated` 站立狀態；普通開關開合亦保存 |
| `contacts` | 每個人對應 `null` 或一個可觸家電 ID；目標必須存在，且手部位置與家電外殼相符。切換站立狀態保留手部位置，移動人物或家電、換外殼款式時解除接觸，選擇離開把手移離外殼。沒有接觸合法；不能指向插座、電源或普通接點 |
| `timeSeconds` | 有限、非負的模擬時間 |
| `protection` | 按元件 ID 保存斷路器／漏電保護器的 `closed / open / tripped`、熔絲的 `intact / blown`，以及相應超額／差流累計秒數；類型、範圍和狀態須相符。`bodyCurrentSeen` 記本次合資格計時區間曾有人體電流；動作時轉存 `bodyCurrentBeforeTrip` 並記原因，不能因跳掣後電流變零而隱去曾有人體電流。低於門檻／手動斷開清空區間，復位清空事件 |
| `energyKWh` | 只為現存電能表保存有限非負累計值；不能把派生的即時功率當作權威答案 |
| 不保存 | 導體角色推導結果、電流／電壓、DOM、捕獲、拖動預覽、手指位置、動畫、全螢幕及開啟中的面板；載入後由權威資料重建 |
| 外部限制 | 元件白名單、接線規則、模型常數及操作權限來自可信配置；匯入文件不能改寫它們 |

上表每個欄位已落成嚴格 schema 與 production fixtures；沿用共用容量上限，不新增自動存檔系統。匯入完整驗證後才替換，失敗保留原工作台。未知版本拒絕；DC／AC 檔交由各自工作台，沒有隱式轉換。

| 可保存狀態 | 合法續作／恢復要求 |
|---|---|
| 空白、部分接線、未接地 | 繼續取元件、接線；不補答案、不標成損壞文件 |
| 家電工作線九種接法、E 引線錯接或留空 | 原樣恢復孔位、線芯標示與拓撲；播放求得相同結果，再拖動其中一條線得到新回路。錯接是有效文件，不自動更正或拒絕載入 |
| 正常工作、電表已有累計 | 載入先暫停；播放後由原累計及時間繼續 |
| 故障已設，但沒有回流路徑 | 保留故障與零漏電流的區別；人接觸或接地後重新求解 |
| 人在地上／椅上，已接觸／未接觸 | 保留姿態及目標；切換其中一項得到相應回路 |
| 保護計時途中 | 保留合法計時；繼續播放後在同一模型事件邊界動作 |
| 已跳掣／已熔斷 | 保持斷路；復位／更換後才可能通電，不能因匯入或改故障而復原 |

復原／重做恢復同一命令邊界的電路、接觸、故障、保護和電能，並暫停。拖動／參數預覽使用副本，凍結權威時間，取消不改正式狀態；提交只形成一次操作，不補算操作期間時間。只讀停止時間及變更命令，仍可縮放／讀值／全螢幕；多 instance 不共享時鐘、狀態或事件，destroy 停止其回呼。

## 9. 手機、吸附與接觸操作

沿用共用 20 單位元件網格、24 CSS px 端子吸附距離。模型允許的目標預覽後放手保持；**家電錯接也是允許的目標**，L／N／E 三孔均可吸附，已接另一條家電線的孔亦可選。超出第 4 節模型範圍的目標才不吸附；不把學生移到的錯誤孔自動改成正確孔。工作台不以吸附替學生作答，也不以它評分。

線端／端子／共接點和手部接觸受手指遮擋，使用共用局部放大預覽，顯示實際圖形及吸附位置，放在不遮手的角落；粗略搬動、按掣、選規格不自動彈預覽。完成、取消、切換示例及只讀時清除。

| 目標／區域 | 命中及手勢 | 鍵盤／非拖動替代 |
|---|---|---|
| 元件本體、線端、線身、共接點 | 沿用 `.hit.body / .hit.wireend / .hit.wire / .hit.junction` 的局部目標；精細目標至少 44 px，線身只留局部走廊；捕獲元素在拖動中穩定 | 共用選取、移動、接線／拔線、旋轉命令 |
| 三孔及四端元件接孔 | 共用 `.hit.port`，至少 44 px；按第 4 節區分固定供電接法與家電自由目標，三孔及同孔多線可分辨、選取和拔開 | 檢視器按端子名稱連接；家電引線可選任一孔，不只列正確答案 |
| 人的手與外殼接觸區 | 新局部手部目標至少 44 px，外殼接觸區貼合實際外形；沿用捕獲／預覽和 24 px 吸附，不把人物周圍空白整塊變成熱區 | 「接觸對象／離開」及站立狀態選項 |
| 開關、故障、款式、規格 | 既有按鈕／選項，至少 44 px，不用 hover 才能操作 | Tab、Enter／Space、原生選單 |
| 面板 | 只捲面板，頂／底邊界也不能拖走宿主 | 原生焦點及捲動 |
| 畫布空白及左右捲頁區 | 非操作空白交宿主捲動；保留左右至少 32 CSS px 可觸及捲頁區，不攔截為接觸或取線 | 共用相機按鈕另供移圖 |

以上 selector 為既有類型盤點，實作時以實際產生的目標逐項核對；新手部目標須登記其穩定 selector 及命中範圍。自由接線／彎線與雙指導航沿用共用手勢，不新增全畫面透明攔截層。

source 及解壓 ZIP 都按[完整手勢契約](../docs/simulation-scorm-production-guide.md#selective-touch-gesture-ownership)執行 T0–T3；記錄實際 window／element owner。場景覆蓋空白、已接線、家電錯接／同孔多線、故障／跳掣、人物接觸、實物／符號及只讀，不能只測初始畫面。尺寸包含 320×500、390×500、390×600、一般直向、短橫向、短 iframe、鍵盤及 200% 縮放。T4 真手機／Moodle 另記證據。

### 必須驗證的行為

| 測試組 | 核心正例及反例 |
|---|---|
| 十一類元件 | 端子數／身份、L/N 入出隔離、雙極連動、E 確實連外殼、雙重絕緣無 E、規格／款式切換不丟線 |
| 接線規則 | 兩類家電各自覆蓋全部九種工作線組合、金屬外殼 E 引線接 L／N／E／留空，均須接受；供電側固定身份衝突、開路開關跨角色、接地符號引線繞道仍拒絕。覆蓋未定網路後續合併、整組／雙端吸附、共接點、鍵盤／命令／匯入及兩種接線先後次序；空白／部分接線不得誤擋 |
| 錯接的電氣結果 | 同孔兩線的負載 U/I/P 為 0，故障／人體支路另計；L–L 兩線仍對地帶電。L／N 反接按實際負載工作，故障位置不隨反接移動；N–E 與 L–E 分別驗證接地／懸浮，兩類家電 L–E 在絕緣完整時仍可令 RCD 動作；外殼 E 引線誤接 L 不靠故障開關才帶電。各結果交叉驗證外殼接觸及保護斷開後重算，不能硬編碼「錯接＝停止／跳掣」 |
| C02 必要條件 | 斷 L／斷 N × 絕緣正常／破損 × 接觸／未接觸 × 站地／椅上；確認正常外殼不因斷 N 自動漏電 |
| 接地與人體 | E 完整／未接的功率與外殼電勢；無回路時帶電但無持續電流；雙重絕緣內層破損仍隔離 |
| 兩類保護 | 大負載且 L/N 平衡不觸發漏電保護；小漏電低於斷路器額定值也可觸發 RCD；20／40 mA 及 30 mA 邊界、延時前後、兩極斷開、故障仍在時復位 |
| 數值與事件 | 電阻串並聯／電能解析基準；一般 U/I/P 相對誤差 ≤0.5%，差流絕對誤差 ≤0.1 mA；門檻判定用未四捨五入值；不同幀率／步長及元件順序得到相同事件，時間誤差 ≤1 ms |
| 文件與操作 | 上節每個可保存狀態 production encode/decode/restore 加一次合法續作，包含全部家電錯接及改正後續作；拒絕非法 ID／供電側角色衝突／枚舉／數值／版本，不把家電錯配當壞資料；preview 取消、undo／redo、失敗匯入、只讀、雙 instance 及 destroy |
| 繪圖品質 | 十一類、各家電款式及主要狀態與 AC 基準並排檢視；桌面／手機、縮圖／主圖／預覽／符號、旋轉與多 instance 無線條斷裂、錯誤遮擋、端點偏移或 ID 串色；有實際截圖及修正後檢視紀錄 |
| 圖形與相容 | 八個示例確實可讀並通過第 3 節繪圖驗收；家電原有線芯顏色、實際接到的孔與帶電提示分開；同孔兩線看得清且可分別拔開；source／ZIP 的可信滑鼠、觸控、鍵盤及全螢幕；DC／AC 原接線與文件不套用家庭限制 |

數值測試使用獨立解析值，不以同一求解器的輸出自己驗自己。保護邊界另用可控輸入測試；20／40 mA 是測試治具，不增加學生面板旋鈕。
