第二階段・找出線性關係

由數據點找出直線關係和斜率

圖中橫軸是伸長量 x，縱軸是所掛負載對彈簧的作用力 F。彈簧靜止時，這個作用力的大小等於彈簧回復力的大小。請拖動控制點，畫出一條由原點出發、最能代表三個量度點的直線。因為直線通過原點，其斜率 k = ΔF/Δx = F/x。k 稱為彈簧常數（勁度），單位是 N/m；k 越大，同一作用力造成的伸長越小。你的胡克定律模型是 F = kx。

第三階段・未量度負載的模型預測

用你的模型預測伸長量

每題會指定一條彈簧和一個第一階段未量度的作用力。畫面起初放在未伸長位置（x = 0 cm）。上下移動橙色「預測」標記，設定你預測的伸長量 x；重物會隨標記上下移動，系統亦會用 L = L0 + x 顯示預測總長度。你可以返回第二階段查看自己的數據、直線和 k，已記錄的預測會保留。

第四階段・最大安全負載挑戰

用 F = kx 設計最大安全負載

根據你建立的彈簧常數 k，選擇你預測不會超過伸長上限、而且總作用力最大的方案。這裡顯示的是按你的模型計算的結果；提交後，系統才會用模擬設定值檢查方案是否安全。

做法
  1. 選擇彈簧 A 或 B，查看你為它建立的 k。
  2. 每次加減一個 0.5N 負載塊。
  3. 用 x = F/k 檢查伸長，令 x ≤ xmax，再在安全方案中選總作用力最大的方案。
