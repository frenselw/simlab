# 電路工作台：使用與核心介面

電路工作台是教師用的直流穩態工具。開啟 `sim/circuit-workbench/index.html` 即可使用，也可透過 Live Server。發布包由 `npm run package:circuit` 產生於 `output/circuit-workbench-standalone.zip`；解壓後保留 `circuit-workbench/` 與 `shared/` 的相對位置。

教師入口現在透過 `CircuitEditor.mount` 使用共用編輯器。製作不同學生活動可配置元件白名單／庫存、固定位置、指定參數、介面及本題檢查；現有操作與原 `window.CircuitWorkbench` API 保留。四種操作示例在 `activity-examples.html`，實際配置和 API 見[活動製作指南](circuit-activity-authoring.md)。

這個入口是獨立教師工具，沒有關卡、成績提交或數據記錄／圖像功能。正式學生活動在共用核心外加入自己的題目與評量。後續維護及尚未實作的交流擴展方向見[架構說明](circuit-workbench-architecture-review.md)；現行功能與逐輪驗證見[實作計劃](../plans/28-circuit-workbench.md)，整體審核以[報告記錄的版本](circuit-workbench-audit-2026-10-04.md)為準。

## 課堂操作

- 桌面與手機均由頂欄問號按鈕開啟「操作說明與模型」，包含三步搭建、儀表接法、移圖與讀值；較少用的快捷鍵及模型說明預設收合。控制面板底部不再重複放置說明按鈕或模型文字。
- 工具箱點選元件，拖動本體調整位置；按「取出導線」或畫布下方「＋導線」，取出一條直線。預設共 20 條，取完後按鈕停用，刪線會歸還庫存；已保存的自訂庫存保持。
- 選取導線後可在面板設定該線的「導線電阻」，0 Ω 為理想導線，允許 0–1,000,000 Ω 有限值。頂欄齒輪的「教師設定」可改「新導線預設電阻」，只影響之後取出的線，不覆寫已有導線。阻值是整條線的固定總電阻，拖長、彎曲、拉直或旋轉不會改變；畫布長度不是公尺尺度。導線詳情分別顯示 A／B 端相對電勢、A − B 壓降、電流及耗散功率，設定可復原並隨 JSON 保存。
- 兩端懸空時，拿一個端點只移動該端，另一端保持不動，導線保持直線；拿線身則搬動整條線。拿線身時任一端靠近元件接孔或其他線端會吸附，整條平移至接孔，移開便解除，放手才接好；直接拿端點吸附則固定另一端。接好一端後，拖自由端保留原有彎曲並自然變形，已接的一端保持固定。
- 接好至少一端後，拿線身向任意方向彎曲，也可向電路內側拉和途中轉方向；兩個端點保持不動，包括懸空端，接頭方向隨線自然轉動。只在真正拉盡線長時停止。拿已接端點拉走即可拔開，亦可用畫布下方「拔開 A／B」。懸空或只接一端的線都可保留、儲存和計算。選線後按底部「拉直」或面板「拉直導線」，縮成兩端之間的最短直線；兩端接孔、讀值、長度上限和庫存保持，可復原或再拿線身彎曲。
- 導線平時就在元件上方，重疊處可直接拿線。按「拿導線」（手機「拿線」）可加強線身／線端優先，再按一次返回一般拿取。元件面板也列出所連導線，可直接選取。
- 每條線有最大路徑長度，包含彎曲弧長。預設 600 畫布單位，縮放不改變；拉盡時停止，不能吸附到過遠端子。教師設定可改庫存及新線長度，已取出的線維持自身上限。
- 幾條導線的端點可在空白位置共接成分支；共接不切線，也不消耗額外導線。只有共同端點 ID 導通，線身交叉不導通。拆開一條不會破壞其他線。
- 每次完整編輯手勢算一步復原。Escape、觸控取消、失去捕獲、失焦及視窗變更會取消本次未提交操作；原電路及讀值保持不變。畫布內加入第二指會先取消編輯預覽，再轉為雙指操作；畫布外的第二指或第三指則取消操作。
- 選元件可旋轉、複製、固定、刪除及修改參數。每次旋轉 90° 後，直接接在該元件上的導線會自動拉直；旋轉及拉直可一次復原。點開關直接開合；拖變阻器藍色滑塊直接改變阻值。
- 選取電源、電阻、燈泡或變阻器時，畫布下方直接顯示其主參數，可按 −／＋或輸入數值；電源調電動勢，電阻／恆阻燈調電阻，熱燈調額定熱態電阻，變阻器調滑片百分比。讀值即時重算，可復原，無需展開操作面板；其他設定仍在面板。固定參數、只讀及活動不准修改的參數不出現快捷控制。底部按鈕與縮放百分比採相同欄寬，窄手機按需要換行；拖動期間保持工具列高度。
- A/V 電錶旋轉時，錶身、錶面和三個接孔一起旋轉，所連導線改為新端點之間的最短直線。外部讀值保持正向，亦可按「看刻度」放大閱讀。旋轉不換孔、不換量程、不增加線長；拉直後仍太短的線會阻止旋轉，原角度和曲線保持。
- 選取 A/V 表可按畫布的「⇄ 接孔」或控制面板的「左右換接孔」，把共用負孔與大量程正孔左右換位，小量程孔仍在中間。錶盤不反字；接線跟隨原孔，量程與有號讀數保持。沿用旋轉權限，線太短時整次拒絕，原接線保持。複製、JSON、模板及復原／重做保留此方向。
- 課堂範例已分開主回路和量測支路，保留直線並使用局部圓角。全電路歐姆定律的 V 表跨接電源兩端，設定 A 表內阻後仍量度路端電壓。A/V/W 範例的電壓感測線有一個白色隔開的交叉，沒有接點便不導通。範例按路線準備有限的較長導線；自行取出的新線仍用教師設定的上限。
- 「探測」先點一個端子看電勢，再點另一端子量電勢差。在端子面板按「設為 0 V」改參考點。
- A 表串聯；V 表並聯。三孔均接共用 − 和其中一個正孔：A 為 0.6／3 A，V 為 3／15 V。接哪個正孔便用哪個量程；外觀切換不改接線。先用大量程，確認後再換小量程。W 表的 I+/I− 串聯，V+/V− 跨接負載。
- 指針 A/V 表的正側有 30 小格，零點左側另有 10 小格，零點在全弧的 1/4 處。兩行刻度為 A：−1 至 3 A／−0.2 至 0.6 A，V：−5 至 15 V／−1 至 3 V；A 每格 0.1／0.02 A，V 每格 0.5／0.1 V。指針按實際讀值與所接量程線性偏轉，反接時可讀負值；按「看刻度」放大。較小量程提高讀數分辨率，沒有宣稱儀表校準誤差等級。
- 反接與超量程在元件面板及放大錶盤有提示；低於負滿刻度時同時提示「負向超量程 · 反接」。指針只到兩端刻度外各 2% 正量程的機械限制，數字保留實際有號值。未接或缺共用 − 孔時機械指針回零，數字仍為未知；浮接／無可靠解或同時接兩正孔時不畫正常指針，兩正孔同接必須改接。
- A/V 指針由當前位置帶慣性擺向新讀數，超越後來回衰減至穩定；改參數、反接及換量程保留當前位置與速度。畫布、手機持續預覽及放大錶盤同步，數字採即時穩態解。「暫停動畫」凍結針位，減少動態偏好直接顯示目標。動畫位置不寫入 JSON 或復原歷史，SVG 匯出採穩定讀數。
- 物理量、讀值、單位與刻度用本地 LaTeX 引擎渲染為 SVG 字形：變量斜體、數字及單位直立，科學記號有乘號及上標。畫布、詳情、探測和 SVG 匯出共用排版；中文與自訂名稱維持介面字體，數值輸入仍可直接編輯。下載包不需要 CDN 或遠端字體。
- 教學模式選「固定元件，只接線」；可另外開放旋轉、所有參數或某個元件的參數。這是教師操作規則。
- 「儲存」保存可再編輯的 JSON；「另存固定元件模板」只保留元件；SVG 匯出供講義／投影片使用。
- 復原／重做涵蓋清空、匯入及套用範例。重新整理開始新的示範，不會自動恢復先前文件。
- 手機初始收起面板，顯示完整電路；「＋導線」保持可用。「工具」可開關面板。兩指在中央畫布上拖動可移動整圖，捏合可縮放，以兩指中點為中心，不用切換原工具；放開其中一指後，先放開餘下手指，再繼續接線。亦可選「手掌／拖畫布」後用一指移圖。「全圖」包含所有懸空線；導線端點在小倍率仍有 44 px 命中區。電錶三孔在所有倍率均可拖接：導線端點進入 24 CSS px 範圍時按最近距離吸附，藍圈及「將接到」提示顯示實際共用 − 孔或正孔量程，放手後才寫入接線。低倍率不鋪設互相重疊的接孔點擊按鈕；孔太近時可用「放大所選」輔助，亦可用面板端點選單精準接孔。
- 低於 40% 的全圖概覽暫時收起元件及接孔文字，避免名稱擠在導線上；畫布有「放大查看元件」提示。畫面夠高時，下方空白處列出前三個儀表的實際讀值。放大後恢復完整標籤；點元件仍可查看名稱、參數並「放大所選」。這些概覽排版不寫入文件，SVG 匯出使用完整比例，尊重顯示開關。
- 元件名稱和數值會一起在附近尋找空位，避開導線、旋轉後的元件、端子文字和其他標籤。長名稱會換行，較遠的標籤用細虛線指回元件；移動或拉線時自動更新。「顯示與教學」內的「顯示元件名稱」和「顯示畫布讀值與參數」分開控制，設定隨 JSON／模板保存並套用於 SVG 匯出。
- 桌面用滑鼠滾輪以游標為中心縮放；在畫布空白處雙擊左鍵，第二下按住並拖曳，可暫時移動畫布，放開後恢復原工具。此雙擊捷徑不作用於元件、接孔或導線。亦可中鍵拖動，或按住空白鍵再左鍵拖動。觸控板可按住空白鍵再雙指滑動，或啟用手掌工具後雙指滑動；Mac 三指拖動配合手掌工具或空白鍵。手掌／空白鍵期間的水平及垂直滑動都平移，Ctrl + wheel 的捏合訊號優先縮放。快捷導航不改電路、讀值或復原歷史；編輯拖動期間忽略滾輪，維持接線座標穩定。未用來導航的空白鍵仍可啟動聚焦的畫布按鈕；拖動或滾輪導航後放鍵不會誤開關，文字輸入不受快捷手掌影響。
- 畫布使用全闊空間，預先保留觸控給編輯及雙指操作；單指在空白處滑動不捲動播放器。左右底角各有 32 × 64 px 的捲頁把手，上下滑動可原生捲動外層頁面；面板獨立捲動。從畫布開始的拖動越過把手仍保持原操作。依使用者要求的[第 28 節版面修訂](../plans/28-circuit-workbench.md#28-手機畫布用盡兩側空間2026-10-03)，短把手取代整高灰色側帶；雙指擁有者沿用第 26 節。
- Tab 選導線端點，方向鍵搬動；面板的 A／B 接線對象選單及「接好」提供鍵盤替代。方向鍵亦可移動元件／共接點／變阻滑塊，R 旋轉，Delete 刪除，Escape 取消，Ctrl／⌘ Z 復原。

## 物理界限

0 Ω 理想導線為等電位；正電阻導線是電阻支路，會產生壓降及耗散功率。電勢顏色按導線弧長線性插值，端孔保留各自真實電勢；只有零阻外部路徑會標為短路。電源內阻與 A/W 電流線圈內阻可設 0；V 表／W 電壓線圈的輸入電阻欄位 **0 代表理想無限大**，其他正值才代表有限電阻。

線性電阻使用 MNA 的獨立支路電流及 `V − R I = 0`，避免高輸入電阻的微小導納與低阻節點大數相加後丟失耦合。有限電壓表可確定原本獨立回路的相對電勢；真正理想輸入仍不建立導通。零空間檢查保留理想電源環路的電流歧義。按各未知量消去時的 RHS 量級及最後讀值內積估計 roundoff，把平衡橋的浮點殘差辨識為零；不用全域固定電流門檻，仍保留真正極小的有限電流。0 Ω 導線使用兩側 KCL cut 中估計誤差較小的一側，避免大負載的相消掩蓋並聯電表的微電流；交換導線記錄方向只反轉電流符號。

A/V 表高量程正孔是 a，共用負孔是 b，低量程正孔是 c。教師可自訂高量程參數，低量程為其 1/5，兩行刻度會重新計算。所設內阻是高量程等效輸入值；低量程 A 支路取 5 倍、V 支路取 1/5，為等滿刻度負擔的教學近似。兩個輸入支路均參與求解，包括兩正孔同接的錯誤接法；顯示診斷而不擅選量程。A/V 機械指針採自然頻率 14 rad/s、阻尼比 0.4 的二階運動示意，未依特定實體錶頭校準；不改直流電學解。未模擬校準誤差、保險絲及損壞。

正電流採端子 a → b 的被動符號，元件吸收功率為 UI。電源端口輸出、內阻損耗與總供能分開報告。W 表讀值為電壓線圈的電壓乘以電流線圈電流，保留反接符號；有限儀表電阻會影響電路，不能與非侵入式探測混淆。

熱效應燈是額定點校準的**教學近似**：冷態電阻取額定熱態的 1/10，環境／額定模型溫度為 293／2600 K，使用線性電阻溫度關係及四次方輻射散熱平衡。這些是本工具的明示模型常數，不是某種燈泡的實測材料擬合；沒有預熱、燒毀或光譜模型。

互不相連的電路各有自己的任意參考點。理想探測不能替浮接區定出跨區電壓。無解／未收斂讀值顯示 —；理想支路或導線環路電流不唯一時也顯示 —，不畫假方向。其他可解的獨立電路繼續顯示。電子及常規電流箭頭共用自適應速度，電子沿相反方向；零／未知電流不畫移動。每個電氣連通區取當前導線及元件支路的最大有限非零 |I| 為 Iref，速度採 18 + 222 / (1 + 2 sqrt(Iref / |I|)) CSS px/s；同一區最大電流約 92 px/s，小電流亦保持至少 18 px/s 的可見速度。沒有固定微電流截止門檻，互不相連的電路各自調整。同一區較大電流較快，但速度比例經壓縮，不能當作真實漂移速度、精確電流比例或跨不同電路／工作點的絕對安培比較。粒子間距仍為 65 CSS px。每條線累積有號位移，改電流／反接／切換方向模式不跳位；暫停及背景不累積，恢復不補跑背景時間。位移不存進文件或復原歷史，載入後重置，SVG 匯出保留目前位移。原有連續位移及導航見[第 34 節](../plans/28-circuit-workbench.md#34-電流大小與示意速度mac-觸控板導航2026-10-03)。

二極管、電容、電感、繼電器及瞬態仍屬後續階段；本版不聲稱已模擬充放電或磁場暫態。

## 模組邊界

- `component-registry.js`：端子、參數規格、預設值、直流支路模型與可選 SVG 呈現。
- `circuit-model.js`：結構及庫存／長度驗證、懸空端點引用、拿線／彎線／拔線／共接命令、策略及原子復原歷史。
- `circuit-solver.js`：MNA、非線性迭代、各獨立電路參考點、零空間識別、KCL 導線電流與診斷。
- `circuit-routing.js`：獨立幾何模組：順滑曲線、局部圓角、路徑弧長、有界變形、旋轉接頭修復與舊檔直角避障 A*。不依賴文件模型，讓驗證與編輯測量相同長度；顯示、命中、方向動畫及 SVG 匯出共用實際路徑，不決定電氣導通。
- `circuit-math.js`：統一數字精度及受控 TeX，快取內嵌 SVG 字形及實際尺寸。瀏覽器使用本地 `mathjax-tex-svg.js`，Node 測試使用固定版本 `mathjax-full`；皆為 MathJax 3.2.2，SVG `fontCache: none`，沒有外部字形引用。隨附 `mathjax-license.txt`，來源為該 npm 套件的 `es5/tex-svg.js` 與 Apache-2.0 授權檔。引擎與字形策略見 [MathJax SVG 文件](https://docs.mathjax.org/en/v3.2/options/output/svg.html)。
- `circuit-label-layout.js`：以 CSS 像素、實際介面字體及數學 SVG 尺寸放置資訊，使用局部碰撞索引、四邊候選位置及必要換行；長數值組合只在量與量之間分行。位置、偏好和引導虛線都是瞬時顯示；不改導線、電氣結果、命中或文件。極密畫面可能沒有足夠空位，仍可放大或關閉部分資訊。
- `circuit-renderer.js`：實物／符號、數字／指針、讀值、電勢與方向。未完成操作不寫入電路文件。
- `circuit-meter-motion.js`：A/V 指針的解析阻尼運動、機械限位與臨時狀態；只影響畫面，不參與求解、文件或量測資料。
- `circuit-snapping.js`：純元件拖動吸附預覽，按實際接孔對準懸空線端／共接點，保留既有連接及有限線長。編輯器另負責活動權限、放手提交、取消及歷史；不改文件版本。
- `circuit-document.js`：版本化 JSON、舊元資料遷移與模板匯出；先驗證後替換。匯入內容不能包含可執行模型。
- `main.js`：教師配置與啟動；`circuit-editor.js`／`circuit-editor-ui.js`／`circuit-profile.js` 共用畫布、介面與活動限制，所有變更在驗證後才完成。
- `circuit-checks.js`：共接、串聯、參數及滑片效果的純檢查；不擁有分數、提交或 SCORM。`activity-profiles.js` 提供四種配置示例。

電路文件 v6 包含 `kind/version/components/junctions/wires/cables/policy/display`。`cables: {count, length, resistance}` 記錄有限庫存、新線最大長度及預設總電阻，各線另有必填 `resistance`（有限 0–1e6 Ω）、`length` 最大路徑長度，`shape: auto|free|smooth`、`via` 及兩個端點 ID。端點為 `componentId:portKey` 或 `junctionId:p`；懸空線端是單線使用的接點，多線使用同一接點才相連。量程與接線狀態由拓撲推導，不另外儲存。新線與拖動後的線形保存實際採樣折線 `free`。彎線在原形上施加固定參數的平順位移場，於所拿位置正規化，完整保留拖動方向；端點固定，接頭切向可轉動。局部回彎以共享切向的三次曲線圓順，先依方向變化細分，再把有限採樣分配到彎曲處；平滑不會縮回整段拖動。只有實際弧長及文件座標界限參與可達範圍限制，不能用採樣轉角作二分判斷。顯示／命中／長度驗證共用該折線。`auto` 最多 24 個內部點，其他形狀最多 96 點。

v1–v5 先按各自原版本嚴格驗證，再遷移為 v6。舊線及新線預設阻值補 0 Ω；舊版拒絕新 resistance 欄位，v6 的 cables.resistance 可省略並正規化為 0。舊 a/b 接線及自訂量程保持意義；A/V 接孔位置更新，相關導線跟隨變形並增加接孔移動所需的有限長度餘量。其他路線保持；v1/v2 補有限庫存／線長，超過 10 條的舊檔按實際數量保留。檔案上限 256 KiB，元件／接點／導線上限為 80／600／240。JSON 匯入拒絕超庫存、超弧長、非法引用／數值及未知欄位。

v4 的 `display.names` 為可選布林，控制外部元件名稱；舊 v1–v4 檔案缺省時補 true，新存檔明確保存。`display.values` 繼續控制讀值／參數及儀表讀數。兩者均嚴格驗證類型；自動標籤位置不寫入 JSON。

新文件的 `display.quantities` 預設 `{loadResistance:false,loadPower:false,sourceResistance:false,rheostatResistance:true}`：畫布保留電源電壓、滑動變阻器電阻與儀表讀值，隱去固定電阻／燈電阻、用電器功率及電源內阻。控制面板「進階內容」可獨立勾選前三項，變阻器電阻亦可獨立關閉；數值總開關仍可一次全隱藏。選取元件後的編輯參數／實際讀值保持可查閱。兩外觀、標籤避讓及 SVG 匯出共用過濾。舊檔缺整組時補全 true，保留當時完整標籤；提供該組時，四字段都須是布林，缺項或未知項拒絕。選項明確保存於 JSON／模板及復原歷史。

A/V 元件可保存 `mirrored` 布林，缺省 false；其他元件不接受，舊 v1–v3 不接受 true。接孔先在元件局部座標左右反射，再按原角度旋轉；孔 ID、高低量程、極性及電學模型不變。實物引線／可見孔、標記、吸附及命中共用 `CircuitRegistry.localPorts/ports`，換位後有限導線會修復接頭路徑並保留遠端。幾何相機／路徑快取包含此方向。

`CircuitModel.addWire(doc,x,y)` 是互動取線命令；`moveWireEnd/attach/detach/bendWire` 保持有限長度與端點拓撲。`connect()` 供教師網表／預設構造，可明示既有較長路線，仍消耗庫存並保存有限上限；互動介面不能以點端子呼叫它。元件搬動後以 `reconcile(doc,before)` 維持連接並檢查可達性，不能任意搬到短線達不到的位置。旋轉使用 `rotateComponent(doc,id,direction=1)`，原子完成順時針（1）／逆時針（−1）90° 旋轉、所連導線拉直與有限長度檢查；無關導線及共接點位置保持。

`reconcile` 的 A/V 接孔換位修復使用 `CircuitRegistry.bodyBounds()` 的旋轉後錶殼及接孔朝外方向，在中心四周各 200 畫布單位的固定區域重新接回原線身；新接頭路徑不能跑出該區域再繞回來，避免連續旋轉累積繞圈。區域外線形及無關導線保留；整條線都在附近或兩端在同一錶上時，修整該條線。若原線重入新錶殼，須替換至離開錶殼的位置。沒有可達的路徑或超出有限弧長便拒絕整次操作，不能把過長路線壓直穿過錶殼。普通搬動仍沿用原變形；新幾何寫入既有 `free/via`，不改舊 `auto` 線的讀檔解讀或文件版本。使用者觸發旋轉則由 `rotateComponent` 將所連導線設為 `free`／空 `via` 的直線，不採接頭繞殼修復。

## 工作台介面

載入頁面後使用 `window.CircuitWorkbench`：

| 方法 | 行為 |
|---|---|
| `getDocument()` | 回傳目前已提交電路的副本，沒有指標或拖動預覽 |
| `exportDocument()` | 驗證後回傳 JSON 文字 |
| `loadDocument(objectOrJson)` | 驗證全部內容、原子載入並重算；錯誤會拋出，原電路保留 |
| `getAnalysis()` | 電勢、元件、各支路、導線、參考點及診斷的副本 |
| `voltage(firstEndpoint, secondEndpoint)` | 兩點電壓；不能確定時回傳 null |
| `applyPolicy(partialPolicy)` | 取消暫態，設定 `mode/allowRotate/allowParams/allowSwitch` |
| `onChange(callback)` | 訂閱已提交變更；回傳取消訂閱函式 |
| `cancel()` | 取消本次未提交拖動，回復已提交狀態 |
| `getInteraction()` | 讀取相機、選取、工具及暫態手勢；雙指時 `dragging` 為 `camera`，另有 `touchCount/touchBlocked/spacePan`。這些值不屬於權威文件 |

計算 API 使用 `CircuitSolver.solve(validDocument)`。每個元件結果包含 `voltage/current/power/branches`；一般元件的 `voltage/current` 對應第一支路，A/V 則對應所接量程支路，`power` 一律是各支路的吸收功率總和。儀表另有 `reading/unit`；A/V 有 `activePort/range/minimum/division/meterStatus`，`minimum` 為該孔正量程的 −1/3，狀態為 `normal/reverse/overrange/unconnected/missing-common/dual-positive/unknown`。電源另有 `delivered/internalPower/sourcePower`。各支路包含端子、電壓、電流與吸收功率；儀表的自身耗電與量測讀值分開。null 表示無可靠或唯一結果；不能當成 0。

## 擴充元件

以**可信的本地 JavaScript**呼叫 `CircuitRegistry.register(type, definition)`，提供唯一型別、名稱／圖示、任意數量端子、參數規格、`dc(component)`，以及可選的 `render(component, result, display)`。文件匯入只承認事先註冊的型別及合法參數。

`dc()` 回傳支路描述陣列，每項包含 `from/to/kind`：

- `branch`：理想或有串聯內阻的電壓約束，附 `resistance/emf`。
- `resistor`：有限電阻，附 `resistance`。
- `nonlinear`：附 `law(voltage, params)`，回傳 `current/conductance`，可另回傳工作電阻／溫度。

模型可讓不同子支路引用不同端子，因此不是把所有元件當成兩端電阻。測試已用一個新增的四端非線性雙負載證明，不改求解器或文件模組便可求解。新增時間狀態仍需設計版本遷移、初始化、步進及能量驗證；目前介面不能冒充時間引擎。

未來 SCORM 外層自行擁有題目、評分與小型權威快照，透過既有 `SimScorm/SimActivityFlow` 管理 attempt。教師完整文件不可直接當成 ≤4000 bytes 的 `suspend_data`，前端策略不能提供高風險評分的安全邊界。

## 作為其他電路活動的基礎

核心可獨立載入及求解，現在亦可用 `CircuitEditor.mount(host, config)` 快速裁剪成學生活動：指定元件／庫存、固定位置／方向、可改參數、介面和本題檢查。學生預設不掛載教師設定；鍵盤、手勢、命令及載入均受相同限制，支援只讀、卸載和多 instance。實際使用見[活動製作指南](circuit-activity-authoring.md)，架構邊界見[共用架構審視](circuit-workbench-architecture-review.md)。題目、評分、記錄圖像與 SCORM 屬各活動外層。

元件本體拖動與導線拖動均能接線。搬動元件時，以 24 CSS px 尋找未接在元件上的線端，接孔對準優先於格點；旋轉及 A/V 換孔沿用 registry 幾何。高亮接孔及預覽不進已提交文件，放手才一次完成位置與接線；多線共接點不能拆散，原有線端不能被搶走，線長不足的候選不成立。手機搬動本體不增加放大浮窗。`component-snapping.test.js` 和 `--component-snap-smoke` 只檢查本輪端點／多孔／線長／拓撲／權限及來源、ZIP 的可信滑鼠與模擬觸控拖接、取消、復原與恢復續作，證據為 `output/playwright/circuit-workbench/component-snapping.json`。

快捷參數由 registry 的 `primaryParameter` 指定，共用編輯器依活動權限顯示；`ui.quickParameters:false` 可完全移除。`node sim/circuit-workbench/quick-controls.test.js` 檢查描述、步長、上下限、權限及文件恢復；`node tools/circuit-workbench-browser-regression.js --quick-controls-smoke` 聚焦來源／ZIP 的 1280、390、320 px 及短橫向排版、可信滑鼠／觸控加減與輸入、復原／續調整、拖動不中斷和學生限制。證據為 `output/playwright/circuit-workbench/quick-controls.json`；手機使用 Chrome 觸控模擬。
