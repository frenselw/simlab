## 1. 產品範圍

### 搬拖板時保持插頭插定（2026-10-16）

已插入的插頭須跟隨接收插座，搬拖板本體只改電源線形狀；只有直接拖插頭才拔開。修正在家庭幾何 reconcile 一處，涵蓋滑鼠／觸控本體拖動、方向鍵、move 命令及元件吸附；保留原有限線長，拉盡時限制本體移動，不自動拔頭。以接收端子及舊三腳重合關係重算原 `plugX / plugY / plugAngle`，不新增保存欄位；明確改插頭參數的拖動不被覆寫，未插入時維持整件搬動。原 household-connections Node owner 補本體移動／線長／接收插座移動／串接、保存往返、復原及明確拔出，不開 Chrome；完成後推送及更新原 Sites。

驗收：正式 editor `moveObject` 的 Node 執行涵蓋搬本體後插頭位置／三路連接／功率／接地不變、線長到限仍保持插入、搬接收插座及拖板串接、未插入整件搬動、保存還原後合法拔出及復原重做，通過；共用元件吸附同樣保持插入，並排除隱藏插頭腳吸附普通線端。household-connections owner 及 component-snapping 的 8 組相鄰回歸、diff 及五包重建／比對通過。沒有新依賴或入口；按用戶要求未開 Chrome，未宣稱可信觸控或真手機驗收。

### 電勢模式覆蓋全部接線顏色（2026-10-16）

用戶確認三選項的電勢模式仍看似身份色。根因是元件引線仍固定 L／N／E 色，家庭外線的漸變又以文件中固定為零的電阻判斷。修正為外線使用家庭分析結果的有效電阻，元件引線依實際端子電勢配色；斷開保護器的入口／出口分開，未知電勢用灰色。同時家庭電勢圖例及線路使用明確低藍／高紅色階，零線與地線同電勢同色。身份模式保持原色；普通模式亦把元件引線統一為普通導線色。拖板外部白線外皮保持白色，內線保持原透明度。不改物理模型、保存格式或 DC／AC 配色。原 presets Node owner 補足三模式元件引線、實際漸變、未知／保護斷開及端子相同電勢檢查，不開 Chrome；完成後重建及更新原 Sites。

驗收：presets Node owner 覆蓋實物／符號的元件引線、外線真正的 gradient paths、L／N／E 不再混色、同電勢同色、斷開保護器出口未知灰色、普通色及保存相容，通過；household-connections owner 的拖板／白線／接地及既有接線亦通過。語法、diff 及五包重建／逐檔比對通過；沒有新增入口或依賴，按用戶要求未開 Chrome。

### 導線顏色三選一（2026-10-16）

家庭控制面板把原「電勢色彩」勾選改為「導線顏色」三選一：火線／零線／地線（預設）、電勢漸變、普通導線。沿用 `display.potential` 控制電勢配色／色階，僅家庭 v8 display 新增可選布林 `roleColours:false` 表示不用身份色的普通導線；省略即沿用原預設，因此舊存檔及 DC／AC 不變。切回身份色或電勢色時移除這個可選旗標。只有身份色模式顯示地線黃綠條紋及 L／N／E 圖例，普通模式使用共用 `#50677e`，選取高亮仍保留。用原 presets Node owner 驗證三種 SVG／正式控制事件、保存往返及舊值相容，調整既有 browser owner 的選項操作但依用戶要求不開 Chrome。無新依賴或入口；完成後重建、推送及更新原 Sites。

驗收：presets Node owner 新增實際 onchange handler 的三選項循環、L／N／E SVG 顏色／地線條紋、完整保存還原後續作、切回預設保持舊 schema 形狀、無效值／非家庭文件拒絕，全部通過；household-state 的 36 個歷史 fixture 往返／續作通過。修改 JS 語法、diff 及五包重建／來源比對通過。沿用既有 test owners，未新增入口；browser owner 已調整成選單操作但未執行。本輪按用戶要求不開 Chrome、不作額外全量測試。

### 控制面板沿用共用高度（2026-10-16）

用戶指出手機控制面板過矮。家庭 CSS 在直向手機把第二列固定為 112 px，覆蓋 AC／DC 共用的 `minmax(112px,31%)`，而且收起時仍可能留下額外列。本輪刪除整條家庭 `.workspace` 高度覆寫，直接沿用共用面板高度、收合及短橫向布局，不另加數值。純 CSS 修正，diff 檢查、重建家庭包及 Sites 同步；依用戶要求不開 Chrome、不加額外測試。

### 移除側邊空白留位（2026-10-16）

用戶截圖確認：先前只縮短把手，家庭 CSS 仍用 `width:calc(100% - 64px)` 及 `margin-inline:32px` 預留全高空間。本輪移除這兩項覆寫，沿用 DC／AC 共用全闊 `.surface` 與底角 32×64 px overlay 把手；家庭原有空白 `pan-y` 保留。沿用共用底角把手的無障礙標示，說明改為底角把手。本節取代先前歷史紀錄中「兩側 32 px 空間保持」的決定。純 CSS／文案修正，不新增測試；diff 檢查及家庭 standalone ZIP 重建通過，依用戶要求不開 Chrome。本輪未重新發布 Sites。

### 三位拖板追加（2026-10-16）

新增 `house-power-strip` 至工具箱，不放入現有示例。三個英式三孔插座以同名 L／N／E 並聯至總插頭；電源軟線只畫白色外皮與邊框，拖板白殼內三條幹線相距 3 單位、以約 12% 不透明度淡顯。沿用原家庭有限通道電阻，不加入負載、開關、保險絲或評分。

插頭有獨立 44 CSS px 拖動目標、24 CSS px 插座吸附、觸控放大預覽及方向鍵替代；三腳一同對準現有插座（亦可接另一拖板空位），拔開即解除三路，佔用插座不能重複插入。外線長度限制 600 世界單位，不能拉斷線；預覽／取消／只讀／復原重做沿用 editor。空白及白色線身不加大型透明拖動覆蓋。

權威狀態為原 v8 元件參數 `plugX / plugY / plugAngle`（相對本體），插入關係由三腳與三孔的精確重合派生；v2 session 無新增欄位，舊文件不變。隱藏幾何參數不出現在數值操作面板。匯入驗證座標、角度、線長及同一插孔佔用；模板匯出不保留隱形插入連接，沿用有直接接觸時拒絕模板的原則。影響元件圖像／定義、共用 editor 的新插頭目標、家庭接線拓撲／求解及原 Node owners；沒有新 runtime 檔案或依賴。用 Node 覆蓋三路接通、三負載並聯、接地／拔線、旋轉插座、佔用、線長／鎖定／取消副本、production 往返續作及 SVG 白線／淡內線；不開 Chrome、不跑額外全量驗證。

驗收：presets、household-connections、household-model、household-state 四個既有 Node owner 通過；新增三位拖板檢查涵蓋三負載功率／總電流／真接地、八個插座角度、拖板串接、重複佔位及過長線拒絕、只讀／禁止改接、復原重做、完整 session 往返及拔線續作、九孔圖像／白線內無彩芯、內線 12% 不透明度，以及 browser 入口實際 script 次序的 VM 載入。check、check:tests（240 entries）、diff 檢查及五包重建／逐檔比對通過；沿用原 owner，沒有新增測試入口或依賴。本輪依用戶要求未開 Chrome，未宣稱可信觸控、真手機或 Moodle 驗收。

- 每個示例只有一個小電路，一般 4–6 件元件；一屏只比較一件事。切換條件在原圖發生，不並排堆兩套大電路。

- 家庭功能由配置及共用擴充接入，不另造分頁式課程、全屋面板或第二套畫布。

| 8 | **金屬外殼用電器**：外殼、內部用電部分及三芯線 | 標示 L／N 的兩條工作引線接內部負載；標示 E 的引線以可見導線及螺絲接外殼。標示表示預定用途，不限制實際接入哪條供電線 | 選熱水器 2000 W、冷氣機 1000 W、金屬外殼風扇 60 W；切換「正常／絕緣破損（外殼漏電）」。三條引線都可錯接或不接；外殼有可供人接觸的區域 |
| 9 | **雙重絕緣用電器**：可見兩層絕緣及雙方框標記 | 只有預定接 L／N 的兩條工作引線，沒有 E 引線；內部用電部分與可觸外表之間有兩層隔離 | 兩條引線均可接 L／N／E 任一節點或不接。選雙重絕緣攪拌機 400 W、風扇 60 W、吹風機 1200 W 或吸塵機 700 W；切換「正常／內層絕緣破損」，第二層仍完整，不形成外殼漏電支路 |
| 10 | **人**：清楚的手、身體及腳 | 左右手各有可吸附導線的接線點，右手也可接觸用電器外殼；兩手經人體電阻相連，腳的對地通路由站立狀態決定 | 選「站在地上／站在絕緣椅上」；拖線端到手掌、拖雙手到未接線端／共接點、拖右手到外殼，或在面板選擇接觸對象／離開。接地、接線、接觸及電壓條件共同決定人體電流；有電流時人物表情繃緊及顫動，顯示實際人體電流路徑，電流歸零即恢復 |
| 11 | **漏電保護器**：雙極手柄及「漏電 30 mA」標記 | L 入／出、N 入／出，共四端；比較經過自身的火線與零線電流 | 漏電差流達演示條件後，同時切斷 L／N；可手動開合／復位。首版固定 30 mA，不增加靈敏度選單，也不兼作過電流斷路器 |

### 插座與家電的畫法

三孔使用**插座正面視角**。每孔是一個電氣節點；供電側按固定身份接入，家電側接到學生實際選中的孔，以簡化透視線顯示導通，不額外增加六個容易混淆的孔。同一孔可容納多個圖上連接，兩條家電引線同接一孔時，共接關係與兩條線都要看得見，不能被單線命中或圖層覆蓋。這是接線原理圖，不模擬把裸線插入插座。首版不新增獨立插頭、插拔動畫或鏡像視角。

金屬外殼元件的 E 引線–外殼連線始終可見；正確接線時的正常工作路徑為 L–負載–N，不經外殼。錯接時保留原有線芯顏色、L／N／E 標示及內部接點，不能偷偷交換標籤或重畫成正確接法。雙重絕緣元件即使內層出現裂口，也要看得見仍完整的第二層。

上述功率是選定教學款式的**額定輸入功率**；冷氣的 1000 W 不表示製冷量，同一類家電也不一律屬同一絕緣類別。切換款式保留元件 ID、位置、相應接線及故障狀態，重算負載；不自動復位保護裝置。

## 4. 接線規則：容許用電器接錯，再觀察結果

### 預定用途、實際連接與電勢分開

- 供電側的市電、電表、斷路器、漏電保護器及插座有固定 L／N／E 端子身份；端子身份固定，但容許相互錯接，由實際電流、電勢及保護動作呈現結果。
- **用電器引線上的 L／N／E 只表示預定用途，不能當作拒絕錯接的硬性配對條件。** 兩條工作引線可各自接入任一 L／N／E 節點，兩條也可接到同一節點；兩類用電器及所有款式一致適用。金屬外殼的 E 引線亦可錯接 L／N，或留空。
- 線色仍為 L 棕、N 藍、E 黃綠雙色，另有字母。家電自帶線芯的原色與標示固定；一般自由導線未接已知供電端時為灰色，接上後由實際供電節點推導。不能因錯接而把家電藍色線芯改成棕色，或把插座 N 孔改名為 L。
- 固定身份沿外部導線、共接點、插座同孔、電表／保護器的各自通道傳遞；普通開關也可跨接不同角色；端子名稱不改，實際開合由電氣模型處理。**家電端子的預定用途不向外傳成固定身份；角色不跨負載、電源、故障支路或人體傳遞。** 實際電氣求解仍包含這些支路。
- 拔線後重新推導實際連接；不保留過時身份。接錯、自由端、未接齊或未接地都是可保存的學習狀態，不能自動修正。
- 電勢由模型求出，不由線色或標籤決定：藍色家電引線誤接 L，或零線開關斷開後的負載側藍線，都可能相對地帶電。

### 開放與限制的界線

| 嘗試接法 | 結果 |
|---|---|
| 供電側 L 接 L、N 接 N、E 接 E；同角色分支 | 接受；電表及保護器仍按各自通道連接 |
| 供電側固定 L／N／E 端子互接，或用一條線／共接點直接短接不同供電角色 | 接受；L–N／L–E 可形成低阻故障，N–E 的回流按模型求解，不只因接錯便跳掣 |
| 家電的兩條工作引線接 L／N／E 任意組合，包括兩條同接一孔 | **接受全部九種組合**；不要求先啟用「錯接模式」，也不只在指定示例開放 |
| 家電 E 引線接 E、錯接 L／N，或不接 | **接受**；外殼跟隨實際接入的節點。錯接 L 時即使絕緣完整，外殼也可能帶電；錯接 N 不視為正確保護接地；不接時不自動補地線 |
| 經家電負載形成 L–N、L–E 或 N–E 通路 | 接受；負載兩端接不同角色不等於用裸導線把供電端短接 |
| 普通開關串在火線／零線 | 均接受；接 N 時給「開關接在零線」的中性提示，保留原比較 |
| 開關兩端分別接不同供電角色，或串入 E；保險絲串在 N／E | 接受；保留各端子及線芯標示，由實際接法決定開合、短路或保護失效 |
| 普通導線接接地符號 E 接線點 | 接受任一端拖接、共接點分支及接往插座 E、家電地線或手部；也容許不同供電角色的錯接，按有限線路阻抗求解 |
| 人的手碰外殼 | 走獨立「接觸」操作；不是接線，不受 L／N／E 配對規則誤擋 |
| 圖上導線交叉但沒有接點 | 不導通；沿用 DC 的明確共接點操作 |

**所有入口執行同一規則。** 拖線、拖元件靠近線端、兩端同時吸附、共接點合併、鍵盤接線、公開命令、示例載入及文件匯入都要同時支援上述錯接與限制。供電端子及家電線芯標示只表達身份及預定用途，角色混接不構成壞文件；同一手／引線把 L 與 N／E 合併也保留並計算低阻故障。仍驗證元件／端點存在、枚舉、數值、庫存、有限線長及操作權限，非法資料原子拒絕，不留下半次接線或多餘復原紀錄。

### 用電器兩條工作引線的接法與結果

下表依序寫「家電標 L 的引線接哪裏、標 N 的引線接哪裏」。基準為同一個正常供電的插座、E 已接等效地、絕緣完整、沒有人接觸，金屬外殼 E 引線若存在則正確接 E。這是第 6 節電阻模型的推論及驗收基準；其他接法／故障／保護狀態按實際電路重算。

| 接到的節點 | 基準結果及要呈現的概念 |
|---|---|
| L–N | 兩端約 230 V，正常工作 |
| N–L | 兩端仍有約 230 V；本版電阻等效負載可工作，但預定 L／N 已反接，不能因能工作便顯示「接線正確」 |
| L–L | 同一節點，負載兩端電壓為 0，沒有工作電流；兩條工作引線仍相對地帶電，不能顯示為已隔離或安全 |
| N–N | 同一節點，負載兩端電壓為 0，沒有工作電流；不能因此宣稱任何情況下觸碰均安全 |
| E–E | 同一節點，負載兩端電壓為 0，沒有工作電流；地線不能因此被解讀為第二組正常供電孔 |
| N–E、E–N | 本基準中兩端近 0 V，電器不工作；不同節點間的實際壓降仍交求解器計算，不能把 N 與 E 視為可互換的接線身份 |
| L–E、E–L | 地回路完整時可有約 230 V 及工作電流，但電流錯經地線回流。若 L 經漏電保護器而回流繞過其 N 通道，按實際差流及延時跳掣；不能一律當開路，也不能只看「接錯」就跳掣 |

E 未接地、保護已斷開、只有一條工作線接上，或另有人體／故障回路時，上表不能作硬編碼答案；重新求兩端電壓、各支路電流及外殼電勢。尤其 L–E 在 E 懸浮且沒有其他回流路徑時可不工作，懸浮側卻仍可能被負載連到火線電勢。

錯接放手後仍留在學生選的位置，不彈回、不改接最近的正確孔、不彈阻塞對話框。畫面只保留一個當前觀察句，例如「兩條線同接火線，電器沒有工作電流」；選取後才顯示兩端電壓、對地電壓及「本應接 N，現接 L」等說明。九種組合表只供規格與驗收，不搬到學生畫面作九張資訊卡。

### 「開關接零線」示例的必要條件

此比較固定家電兩條工作引線按 L→L、N→N 接好，只改開關位置；先正常工作，斷開火線開關或零線開關都能使它停止。再以**相同的外殼絕緣破損、家電 E 引線未接、人在地上並接觸外殼**比較：

- 斷火線：故障點與火線電源隔離，本例沒有持續人體電流。
- 斷零線：火線仍連到故障點，電流可經外殼、人體及接地回路回到電源。
- 絕緣完整時，不能只因開關在零線便畫出外殼漏電；人未接觸且手部未接線，或理想絕緣離地而又沒有雙手等其他回流路徑時，也不能畫出持續人體電流；兩手跨接 L／N 即使站椅仍可觸電。

C01 預設 15 A 斷路器與 2000 W 熱水器；C02–C04 用 60 W 金屬外殼風扇，C05 用 400 W 雙重絕緣攪拌機，C06 用攪拌機與 60 W 雙重絕緣風扇。C07 初始只開 400 W 支路，其餘關閉；C07fuse 初始開關斷開。其他目前示例從正常、開關合上、人物未接觸開始；需要人物時預設站地上，C09 預設站椅及雙手已接線，故障由學生主動切換。C03–C04 預設 E 已接，拔開後才形成無地線的對照。已退役 C08 保留原有 400 W 攪拌機及插座接法供相容讀取。

C03 專注接地回路，C04 才加入漏電自動切斷，避免每例同時講全部保護。C07 聚焦多件家電累積負載，C07fuse 只用單件家電演示熔斷；兩例均不加插座或地線，N 直接回到家電，不虛構保險絲的零線通道。

C08 專注兩條工作線，不加入人物、電表或保護器，也不新增接法按鈕排；用原有拖線及讀值操作探索。需要觀察 L–E 錯接後跳掣時，在 C04 原圖改接家電工作線，並保持絕緣完整，以分清「錯把地線當回線」與「絕緣破損漏向外殼」。

故障及跳掣以局部導線／接點／外殼狀態和一句結果表達。若曾有人體電流後才跳掣，結果必須說「曾有電流通過人體，現已切斷」，不能直接顯示「安全」。

## 6. 物理模型：服務概念，讀值保持一致

採單一市電源的有效值電阻模型，另計保護延時和電能；不逐點積分 50 Hz 波形。電壓／電流標有效值，功率為平均有功功率。交流流動若開啟，只以雙向往返作概念示意，不畫成永久由 L 向 N 流的直流。

| 項目 | 首版規則／常數 |
|---|---|
| 市電 | 230 V、50 Hz 固定；L–N 為供電，電源 N 在供電端連到等效地參考。畫布只引出 L、N，允許學生自行接錯或短接 |
| 負載 | `R = 230² / 額定輸入功率`；依兩條工作引線實際所接節點求端電壓 `U`，再求 `I = U/R`、`P = U×I`。端子標示或「接線正誤」不直接決定工作狀態；同節點端電壓為 0，反接及 L–E 回路也須正常求解。風扇／冷氣亦採此教學等效，不模擬馬達啟動與功率因數 |
| 有限阻抗 | 供電等效電阻 0.05 Ω；每條外接導線、電表、閉合開關及保護器每個通道 0.001 Ω。E–外殼仍為內部理想連接；阻值不因畫面線長變化 |
| 金屬外殼及故障 | 外殼始終導通到家電 E 引線的實際接入節點；E 引線錯接 L 也會使完整外殼帶電，不依賴故障開關。「絕緣破損」另加入家電**標 L 的內部端子**至外殼的 2000 Ω 支路；反接後故障位置不追著供電火線移動。此支路表示受損絕緣，沒有回流路徑時可帶電而尚無漏電流 |
| 雙重絕緣故障 | 只破壞內層；完整外層仍為開路，不加入外殼漏電支路，也不偷偷改成 L–N 短路 |
| 人體 | 兩手各經 1000 Ω 連同一身體節點，站地時身體再經 1000 Ω 接等效地，站椅時只斷開腳的支路。單手至地及雙手之間等效 2000 Ω；兩手跨 L／N 時站椅亦有電流。人體電流讀值取各支路絕對值最大者，避免雙重計數；這是固定教學值，不能預測傷害程度 |
| 地線 | 接地符號表示連回供電系統的等效地，不是把電流「吸走」。正確接線且無故障時 E 無工作電流；工作引線錯接 E 時可承載負載回流，外殼故障時也可承載故障電流，均依實際回路計算。沒接地的插座 E 不自動連到模型地參考 |
| 過電流 | 斷路器／保險絲的電流連續大於所選額定值 2 個模擬秒後動作；達額定值 5 倍則 0.02 s 快速過流切斷，計時種類切換時重算區間；回到額定值以下或斷電時清零計時。這是便於比較的教學延時，不標作真實器件曲線 |
| 漏電 | 比較同一保護器兩通道的有向電流；本模型為同相電阻負載，可用流出 L 與返回 N 的有效值差額。差流 ≥30 mA 持續 0.10 個模擬秒後兩極斷開；未達時清零計時。L–E 錯接即使絕緣完整，也可能因回流繞過 N 而動作；反接但兩通道仍平衡則不只因「接錯」而動作 |
| 復位／更換 | 由使用者操作；故障未排除時重新按電路計算並再次動作。移除故障或提高額定值不會自動合閘 |
| 電能 | 對電表實際供出的功率積分：`ΔE = P × Δt / 3,600,000` kWh。暫停時電能及保護計時同時凍結 |

保護事件按模擬時間處理，分割時間步到事件位置後重算；不依螢幕幀數。多個保護裝置同一時刻達條件時一同處理，再求解，避免結果依元件排列而變。接線／故障／規格改變後先重算，再推進時間。

對地讀值以供電端等效地為基準；不能像各個獨立 DC 小電路自行選零點，再把懸浮外殼報成 0 V。未能確定的電勢顯示「未定」。導體顏色不隨電勢改變；選取時可用額外輪廓提示仍帶電。

三項教學界限放在相關說明內：低阻地線的降壓不等於所有實際接地都可靠；漏電保護器在電流發生後才動作，不能保證不受傷；絕緣椅狀態忽略潮濕、寄生電容及其他接觸，不能當作現實防觸電方法。雙重絕緣「仍不漏電」只適用於本例的單層破損。

供電數據依[澳電供電資料](https://www.cem-macau.com/en/about-cem/company-profile/operation/)；外殼接地與雙重絕緣概念核對[機電工程署電器安全說明](https://www.emsd.gov.hk/tc/electricity_safety/publications/general/household_electrical_safety_handbook/part_2/2_1/index.html)；線色及保險絲規格核對[Electrical Safety First](https://www.electricalsafetyfirst.org.uk/safety-advice/home-and-people/house-maintenance/plugs-and-fuses/)；30 mA 保護及其界限核對[HSE 電氣安全說明](https://www.hse.gov.uk/electricity/electricequip.htm)。上表阻抗及延時是本計劃自行選定的教學參數，不冒充上述來源的實物規格。

## 8. 文件狀態與操作一致性

本版封套為：`kind: "simlab-household-concepts"`、`version: 2`、`model: "concept-rms-2"`。v1／concept-rms-1 經嚴格驗證後轉入新模型；接線、時間、電能及事件保留，舊事件切斷前讀數為 null。撤回原型不屬相容版本。

| 欄位 | 權威資料與驗證 |
|---|---|
| `circuit` | 沿用共用幾何結構的元件、接點、導線、ID、位置及線形；只接受本版十一類元件、枚舉款式／額定值及存在的端子。保存實際接到哪一孔，包括錯接、同孔多線及留空；只按第 4 節拒絕超出模型範圍的接法，不因家電標示與目標不同而拒絕。幾何文件為 `kind: simlab-household-circuit`、`version: 8`、`analysis: household`、`modelRevision: 1`，不能冒充 DC v6／AC v7；市電及接地元件取件不附加導線；所有外接導線均由用戶自行接線，兩端可拔接／刪除。舊檔市電／接地 `anchor` 在驗證時移除，保留接線及幾何 |
| 元件參數 | 家電款式、故障枚舉、所選規格及人的 `grounded / insulated` 站立狀態；普通開關開合亦保存 |
| `contacts` | 每個人對應 `null` 或一個可觸家電 ID；目標必須存在，且手部位置與家電外殼相符。切換站立狀態保留手部位置，移動人物或家電、換外殼款式時解除接觸，選擇離開把手移離外殼。沒有接觸合法；不能指向插座、電源或普通接點 |
| `timeSeconds` | 有限、非負的模擬時間 |
| `protection` | 按元件 ID 保存斷路器／漏電保護器的 `closed / open / tripped`、熔絲的 `intact / blown`，以及 timingMode、相應超額／差流累計秒數、currentBeforeTrip／residualBeforeTrip；類型、範圍和狀態須相符。`bodyCurrentSeen` 記本次合資格計時區間曾有人體電流；動作時轉存 `bodyCurrentBeforeTrip` 並記原因，不能因跳掣後電流變零而隱去曾有人體電流。低於門檻／手動斷開清空區間，復位清空事件及切斷前讀數 |
| `energyKWh` | 只為現存電能表保存有限非負累計值；不能把派生的即時功率當作權威答案 |
| 不保存 | 導體角色推導結果、電流／電壓、DOM、捕獲、拖動預覽、手指位置、動畫、全螢幕及開啟中的面板；載入後由權威資料重建 |
| 外部限制 | 元件白名單、接線規則、模型常數及操作權限來自可信配置；匯入文件不能改寫它們 |

上表每個欄位已落成嚴格 schema 與 production fixtures；沿用共用容量上限，不新增自動存檔系統。匯入完整驗證後才替換，失敗保留原工作台。未知版本拒絕；DC／AC 檔交由各自工作台，沒有隱式轉換。

| 可保存狀態 | 合法續作／恢復要求 |
|---|---|
| 空白、部分接線、未接地 | 繼續取元件、接線；不補答案、不標成損壞文件 |
| 家電工作線九種接法、E 引線錯接或留空 | 原樣恢復孔位、線芯標示與拓撲；播放求得相同結果，再拖動其中一條線得到新回路。錯接是有效文件，不自動更正或拒絕載入 |
| 正常工作、電表已有累計 | 載入先暫停；播放後由原累計及時間繼續 |
| 故障已設，但沒有回流路徑 | 保留故障與零漏電流的區別；人接觸或接地後重新求解 |
| 人在地上／椅上，已接觸／未接觸 | 保留姿態及目標；切換其中一項得到相應回路 |
| 保護計時途中 | 保留合法計時；繼續播放後在同一模型事件邊界動作 |
| 已跳掣／已熔斷 | 保持斷路；復位／更換後才可能通電，不能因匯入或改故障而復原 |

復原／重做恢復同一命令邊界的電路、接觸、故障、保護和電能，並暫停。拖動／參數預覽使用副本，凍結權威時間，取消不改正式狀態；提交只形成一次操作，不補算操作期間時間。只讀停止時間及變更命令，仍可縮放／讀值／全螢幕；多 instance 不共享時鐘、狀態或事件，destroy 停止其回呼。

## 9. 手機、吸附與接觸操作

沿用共用 20 單位元件網格、24 CSS px 端子吸附距離。模型允許的目標預覽後放手保持；**家電錯接也是允許的目標**，L／N／E 三孔均可吸附，已接另一條家電線的孔亦可選。超出第 4 節模型範圍的目標才不吸附；不把學生移到的錯誤孔自動改成正確孔。工作台不以吸附替學生作答，也不以它評分。

線端／端子／共接點和手部接觸受手指遮擋，使用共用局部放大預覽，顯示實際圖形及吸附位置，放在不遮手的角落；粗略搬動、按掣、選規格不自動彈預覽。完成、取消、切換示例及只讀時清除。

| 目標／區域 | 命中及手勢 | 鍵盤／非拖動替代 |
|---|---|---|
| 元件本體、線端、線身、共接點 | 沿用 `.hit.body / .hit.wireend / .hit.wire / .hit.junction` 的局部目標；精細目標至少 44 px，線身只留局部走廊；捕獲元素在拖動中穩定 | 共用選取、移動、接線／拔線、旋轉命令 |
| 三孔及四端元件接孔 | 共用 `.hit.port`，至少 44 px；按第 4 節區分固定供電接法與家電自由目標，三孔及同孔多線可分辨、選取和拔開 | 檢視器按端子名稱連接；家電引線可選任一孔，不只列正確答案 |
| 人的手與外殼接觸區 | 新局部手部目標至少 44 px，外殼接觸區貼合實際外形；沿用捕獲／預覽和 24 px 吸附，不把人物周圍空白整塊變成熱區 | 「接觸對象／離開」及站立狀態選項 |
| 開關、故障、款式、規格 | 既有按鈕／選項，至少 44 px，不用 hover 才能操作 | Tab、Enter／Space、原生選單 |
| 面板 | 只捲面板，頂／底邊界也不能拖走宿主 | 原生焦點及捲動 |
| 畫布空白及左右捲頁區 | 非操作空白交宿主捲動；保留左右至少 32 CSS px 可觸及捲頁區，不攔截為接觸或取線 | 共用相機按鈕另供移圖 |

以上 selector 為既有類型盤點，實作時以實際產生的目標逐項核對；新手部目標須登記其穩定 selector 及命中範圍。自由接線／彎線與雙指導航沿用共用手勢，不新增全畫面透明攔截層。

source 及解壓 ZIP 都按[完整手勢契約](../docs/simulation-scorm-production-guide.md#selective-touch-gesture-ownership)執行 T0–T3；記錄實際 window／element owner。場景覆蓋空白、已接線、家電錯接／同孔多線、故障／跳掣、人物接觸、實物／符號及只讀，不能只測初始畫面。尺寸包含 320×500、390×500、390×600、一般直向、短橫向、短 iframe、鍵盤及 200% 縮放。T4 真手機／Moodle 另記證據。

### 必須驗證的行為

| 測試組 | 核心正例及反例 |
|---|---|
| 十一類元件 | 端子數／身份、L/N 入出隔離、雙極連動、E 確實連外殼、雙重絕緣無 E、規格／款式切換不丟線 |
| 接線規則 | 兩類家電各自覆蓋全部九種工作線組合、金屬外殼 E 引線接 L／N／E／留空，均須接受；供電側角色混接、開路開關跨角色均接受，按閉合狀態計算電氣結果；接地端接受普通導線及共接點。覆蓋未定網路後續合併、整組／雙端吸附、共接點、鍵盤／命令／匯入及兩種接線先後次序；空白／部分接線不得誤擋 |
| 錯接的電氣結果 | 同孔兩線的負載 U/I/P 為 0，故障／人體支路另計；L–L 兩線仍對地帶電。L／N 反接按實際負載工作，故障位置不隨反接移動；N–E 與 L–E 分別驗證接地／懸浮，兩類家電 L–E 在絕緣完整時仍可令 RCD 動作；外殼 E 引線誤接 L 不靠故障開關才帶電。各結果交叉驗證外殼接觸及保護斷開後重算，不能硬編碼「錯接＝停止／跳掣」 |
| C02 必要條件 | 斷 L／斷 N × 絕緣正常／破損 × 接觸／未接觸 × 站地／椅上；確認正常外殼不因斷 N 自動漏電 |
| 接地與人體 | 雙手 L／N／E／未接 × 站地／站椅：單手站椅無回流、雙手跨 L／N 站椅仍有人體電流、同電勢兩手無跨手電流；RCD 後雙手 L／N 站椅時差流為零不跳掣，站地時按腳支路差流動作。E 完整／未接的功率與外殼電勢；無回路時帶電但無持續電流；雙重絕緣內層破損仍隔離 |
| 兩類保護 | 大負載且 L/N 平衡不觸發漏電保護；小漏電低於斷路器額定值也可觸發 RCD；20／40 mA 及 30 mA 邊界、延時前後、兩極斷開、故障仍在時復位 |
| 數值與事件 | 電阻串並聯／電能解析基準；一般 U/I/P 相對誤差 ≤0.5%，差流絕對誤差 ≤0.1 mA；門檻判定用未四捨五入值；不同幀率／步長及元件順序得到相同事件，時間誤差 ≤1 ms |
| 文件與操作 | 上節每個可保存狀態 production encode/decode/restore 加一次合法續作，包含全部家電錯接及改正後續作；拒絕非法 ID／不存在端點／枚舉／數值／版本，不把家電錯配當壞資料；preview 取消、undo／redo、失敗匯入、只讀、雙 instance 及 destroy |
| 繪圖品質 | 十一類、各家電款式及主要狀態與 AC 基準並排檢視；桌面／手機、縮圖／主圖／預覽／符號、旋轉與多 instance 無線條斷裂、錯誤遮擋、端點偏移或 ID 串色；有實際截圖及修正後檢視紀錄 |
| 圖形與相容 | 十個示例確實可讀並通過第 3 節繪圖驗收；家電原有線芯顏色、實際接到的孔與帶電提示分開；同孔兩線看得清且可分別拔開；source／ZIP 的可信滑鼠、觸控、鍵盤及全螢幕；DC／AC 原接線與文件不套用家庭限制 |
